### [2608.04436] ToolArtist: Tool-Using Unified Multimodal Models for Agentic Image Generation

**Score: 83/100** · [arXiv:2608.04436](https://arxiv.org/abs/2608.04436)

**Authors:** Jiahao Zhao, Xiaomin Yu, Zhongxiang Sun, Fengwei Teng, Chengwei Qin, Xiaobin Hu, Jun Xu, Shuicheng Yan

## TL;DR
ToolArtist is the first fully agentic image generation model obtained by post-training a Unified Multimodal Model (UMM) to autonomously orchestrate reasoning, external tool use (text/image search), and native image generation under a single policy — trained via a two-stage SFT data conversion pipeline and a novel RAD-GRPO reinforcement learning algorithm with intent and quality rewards.

## Problem
Current T2I models fail at open-world generation tasks requiring complex semantic understanding, multi-step reasoning, and external world knowledge. Prior agentic image generation approaches either impose fixed workflows or separate reasoning from the generation policy — meaning tool invocation, evidence integration, and image synthesis are never coordinated by a single learned agent. Benchmarks like WISE and WorldGenBench reveal substantial capability gaps in knowledge-intensive domains (cultural details, historical accuracy, geographic grounding, technical specifications).

## Key Contributions
- A fully agentic UMM policy where the agent freely decides at each step whether to invoke external tools (TextSearch, ImageSearch) or perform native image generation — no prescribed ordering between reasoning and generation
- A data synthesis pipeline (Rollout + Convert) that converts trajectories from a teacher agent equipped with an external image-generation tool into UMM-compatible format, where the tool call is concealed but the generated image is retained as native visual tokens — producing 7,132 high-quality agentic trajectories without expensive human annotation
- RAD-GRPO: a reinforcement learning algorithm with dual rewards (Intent Reward evaluating whether generation descriptions capture the user request plus retrieved evidence; Quality Reward assessing faithfulness, visual correctness, text accuracy, and aesthetics) plus auxiliary signals (format validation, draw encouragement, length penalty) to prevent collapse into search-only behavior
- Open release of training data and complete agentic post-training infrastructure for unified multimodal models

## Method
ToolArtist builds on Emu3.5, a UMM that represents both text and images as token sequences and models them via autoregressive next-token prediction. In the SFT Stage I, a teacher agent equipped with TextSearch, ImageSearch, and an external image-generation tool constructs multi-turn trajectories with alternating search-reasoning-generation sequences. Stage II converts these trajectories: explicit image-generation tool calls are replaced by the actual generated images as native visual-token spans, while source-aware image summaries are attached to retrieved images to prevent semantically incorrect visual references. The SFT objective applies loss only over policy-generated tokens (reasoning and action spans), excluding conditioning inputs. The RAD-GRPO RL stage then uses Group Relative Policy Optimization over the full trajectory: the Intent Reward judges caption quality (whether the description accurately translates the user request plus retrieved evidence), while the Quality Reward applies a four-dimensional model (faithfulness 0.1, visual correctness 0.4, text accuracy 0.4, aesthetics 0.1). Token-normalized advantage estimation jointly optimizes all aspects of the agentic loop.

## Why It Matters
By placing the entire open-world image generation process — evidence retrieval, multi-step reasoning, and generation — under a single learned agent policy, ToolArtist shows this consistently outperforms fixed-pipeline or partially agent-controlled approaches. This is a direct advance toward AI systems that autonomously acquire and reason about world knowledge rather than relying on static training parameters. The open infrastructure enables future research into agentic multimodal systems that combine generation with external knowledge grounding — a paradigm shift from model-in-isolation to model-in-the-world for image synthesis.

### [2608.04224] OmniVR: Joint Video-Audio Conditional Generation for Restoring Degraded Historical Films

**Score: 81/100** · [arXiv:2608.04224](https://arxiv.org/abs/2608.04224) · [Project Page](https://xin1u.github.io/OminiVR_PAGE/)

**Authors:** Xin Lu, Zihao Fan, Mingchen Zhong, Jie Huang, Xueyang Fu, Zheng-Jun Zha

## TL;DR
OmniVR is the first joint audio-video generative restoration model — built by adapting a 22B-parameter multimodal DiT backbone via architecture-preserving channel-concatenation conditioning and prompt annealing — that simultaneously recovers visual structure, temporal motion, and acoustic detail under one coordinated objective, outperforming all prior methods on all six visual metrics and achieving the best audio quality and natural colorization.

## Problem
Historical films suffer from co-occurring visual and audio degradations (blur, noise, flicker, hiss, clipping, dropout) simultaneously — 77.5% of clips are degraded in both streams. Existing restoration methods handle each modality independently, leaving quality gaps and cross-modal inconsistency: when only one stream is enhanced, temporal misalignment and asynchrony between audio and video become apparent. A joint approach is fundamentally necessary for coherent archival restoration.

## Key Contributions
- First joint audio-video generative restoration model, formulating restoration as conditional generation within a unified 22B-parameter multimodal DiT — enabling cross-modal attention where audio tokens attend to video and vice versa, producing "mutual promotion" (e.g., lip motion → audio, audio energy → visual sharpness)
- Architecture-preserving T2AV → AV2AV transition via channel-concatenation condition injection with prompt annealing: starts with per-clip captions that linearly decay to a fixed restoration prompt over the first 30% of training, maximally preserving the pretrained generative prior while enabling caption-free inference
- First-frame image-to-video anchoring with loss reweighting for long-video extrapolation (chaining 121-frame windows), plus waveform supervision (multi-resolution STFT loss) for audio spectral fidelity
- OmniVRBench: first audio-video restoration benchmark (200 real historical clips) evaluating across visual quality, audio quality, temporal consistency, and audio-visual synchrony simultaneously

## Method
OmniVR adapts LTX-2 (22B joint audio-video DiT) via LoRA (rank 384) on attention, feed-forward, patch projection, and cross-modal gate layers; encoders and vocoder remain frozen. Condition injection concatenates the degraded input latent channel-wise with the noisy prediction latent; expanded projection weights initialize new dimensions near zero so the model initially behaves as a T2AV generator. Condition noise (ρ ∈ [0.4, 0.6]) during training prevents trivial copying. A joint online degradation pipeline synthesizes realistic old-film artifacts: the visual branch extends Real-ESRGAN with temporally coherent artifacts (flicker, scratches, dust, grayscale), while the audio branch simulates analog defects (hiss, rumble, clipping, bandwidth loss). Per-sample degradation severity scalars enable loss reweighting (self-terms α=1.0, cross-terms β=0.5) that upweights jointly degraded samples to match the dominant real-world regime. Inference uses 15-step Euler ODE sampling with classifier-free guidance (scale 3.0), trained on 64 NVIDIA H200 GPUs for ~5 days.

## Why It Matters
OmniVR demonstrates that coordinated multimodal generation consistently outperforms cascaded single-stream restoration for archival media — recovering irreplaceable cultural artifacts with 80% overall human preference for jointly restored outputs. Beyond historical films, this work shows that large pretrained multimodal generative models can be adapted for fidelity-critical restoration applications through architecture-preserving fine-tuning, without sacrificing the generative prior. OmniVRBench fills a long-standing gap by providing simultaneous multi-dimensional audio-video evaluation. The public release of code and weights enables this joint video-audio generation paradigm to be applied to diverse restoration and enhancement applications.
