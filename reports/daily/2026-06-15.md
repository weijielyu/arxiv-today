### [2606.14168](https://arxiv.org/abs/2606.14168) — MUSE: Agentic 3D Scene Authoring via Memory-Grounded Incremental Requirement Satisfaction
**Score: 84/100** | Agentic AI + 3D Generation

**Authors:** Ruijie Xu, Xinnan Zhu, Jiayu Ying, Daoguo Dong, Yuzhou Ji, Xin Tan

## TL;DR
MUSE is a multi-agent framework for controllable 3D scene authoring that treats construction and editing as incremental requirement satisfaction — using three specialized agents (Architect, Sculptor, Inspector) and three persistent memory stores — improving all-goal success from 37.9 to 80.7 and achieving a 99.9% preservation rate on local editing benchmarks.

## Problem
Text-driven 3D scene generation methods lack requirement-level state tracking: when any sub-goal fails, the system typically regenerates the entire scene. Practical workflows (embodied AI simulation, interactive design) need controllable local editing that tracks satisfied requirements and preserves non-target content across multi-turn interactions.

## Key Contributions
- **MUSE multi-agent framework**: three roles — Architect (parses natural language into structured requirement programs), Sculptor (executes local scene operations against current state), Inspector (verifies requirements with external checkers and updates memory) — enabling verified, incremental scene authoring without full-scene regeneration.
- **Three-Memory Architecture**: Working Memory (active execution state), Scene Memory (placed objects and constraints), Skill Memory (motif-guided reusable operation patterns) enable error recovery, conflict handling, and focus scheduling across turns.
- **AuthorBench**: a new evaluation benchmark with 145 constrained construction cases and a 1,584-case preservation-aware editing pool with external structured verifiers, specifically measuring requirement-level controllability and edit locality.

## Method
MUSE formulates scene authoring as incremental requirement satisfaction. The Architect compiles instructions into a structured requirement program (JSON specifying spatial relations, object constraints, and dependencies). The Sculptor executes local operations grounded in the current scene state, with a local consistency pass to detect conflicts before committing. The Inspector runs external verifier predicates (geometry checks, spatial constraint checks) after each operation, updates memory on success, and schedules failed requirements for targeted retry using Skill Memory patterns — avoiding the full-scene regeneration that prior methods resort to. The closed-loop algorithm continues until all requirements are satisfied or a global feasibility pass signals impossibility.

## Why It Matters
Controllable 3D scene authoring is a critical enabler for embodied AI training environments, game design, and interactive 3D tools. MUSE's multi-agent approach with persistent memory demonstrates that explicit requirement tracking and memory-grounded verification can dramatically raise success rates (37.9→80.7 all-goal) while preserving non-target content (99.9% preservation, 0.6% unintended change rate) — results that single-pass or one-shot methods fundamentally cannot achieve.

### [2606.13768](https://arxiv.org/abs/2606.13768) — CineOrchestra: Unified Entity-Centric Conditioning for Cinematic Video Generation
**Score: 84/100** | Video Generation

**Authors:** Sharath Girish, Tsai-Shien Chen, Zhikang Dong, Mukesh Singhal, Hao Chen, Sergey Tulyakov, Aliaksandr Siarohin

## TL;DR
CineOrchestra is the first video diffusion model to jointly control all four cinematic axes — multi-subject personalization, event timing, camera movement, and shot transitions — through a single unified entity-centric conditioning structure and two novel parameter-free rotary embeddings, outperforming six per-axis specialist models on two new cinematic benchmarks.

## Problem
Current text-to-video models condition on a single global caption and produce a single shot, but cinematic video requires multiple subjects acting at specified times, deliberate camera motion, and shot transitions. Existing methods address each axis in isolation with bespoke architectures — no prior framework jointly integrates all four, forcing laborious multi-model pipelines for professional video production.

## Key Contributions
- **Entity-Centric Cinematic Conditioning**: represents every cinematic element (subjects, cameras, shot transitions) as (start_time, end_time, prompt) tuples with optional reference images — one unified structure with no modality-specific design, reducing architectural complexity to a single positional encoding problem.
- **Interval-Sampled Temporal RoPE**: samples position uniformly within each event's time interval and rescales for duration-invariant attention similarity, handling events spanning 0.1s (hard cuts) to 10s (sustained camera moves) within the same model.
- **2D Entity-Temporal Cross-Attention RoPE**: disambiguates per-entity conditioning tokens and routes each to its correct spatiotemporal region in the video, handling multiple overlapping entities with reference images simultaneously.

## Method
CineOrchestra is built on a video DiT backbone. Each cinematic element is represented as a structured tuple with unique tag ({man}, {camera}, {transition}), temporal interval, description, and optional reference image. The two coordinated RoPE designs handle the positional encoding challenge: interval-sampled temporal RoPE normalizes attention behavior across dramatically varying event durations; entity-temporal cross-attention RoPE tiles entity and temporal position indices jointly so each entity's conditioning attends to the right spatiotemporal region. The model is trained on curated cinematic data with automated annotation of entity-centric conditioning primitives, learning a single unified representation for subjects, cameras, and transitions.

## Why It Matters
Cinematic video generation is a high-value capability for film production, game content, VR, and interactive storytelling. CineOrchestra's unification of all four cinematic axes in one model — outperforming six per-axis specialists — is a qualitative step change from today's fragmented landscape of single-axis tools, enabling single-pass generation of complete multi-subject, multi-shot scenes with camera control.

### [2606.13872](https://arxiv.org/abs/2606.13872) — Avatar V: Scaling Video-Reference Avatar Video Generation
**Score: 84/100** | Human Video & Face + Video Generation

**Authors:** Benjamin Liang, Ce Chen, Desmond Lin, Ivan Somov, Jiajun Zhao, Jiewei Yuan, Jingfeng Zhang, Junhao Huang, Nik Nolte, Pedram Haqiqi, Penghan Wang, Rong Yan, Rui Zhang, Sam Prokopchuk, Sivan Wang, Viktor Goriachko, Yi Ren, Yuanming Li, Yutao Chen, Zhenhui Ye, Zhibin Hong, Zilong Nie, Zujin Guo (HeyGen Research)

## TL;DR
Avatar V is a production-scale avatar video generation system that conditions on a full reference video sequence — not a static image — to capture both static identity (facial geometry, skin texture) and dynamic behavioral traits (talking rhythm, micro-expressions), generating unlimited-duration 1080p video that outperforms Kling O3 Pro, Veo 3.1, and OmniHuman 1.5 on identity preservation and lip synchronization.

## Problem
Existing avatar video methods compress identity into a fixed-size embedding from a single static image, losing dynamic motion traits like talking rhythm and gestural tendencies. Standard pixel-level training objectives also underserve perceptually critical facial regions, leading to video that looks visually similar to the reference person but fails to be behaviorally recognizable.

## Key Contributions
- **Video-Reference Conditioned Identity Modeling (VideoRef DiT)**: conditions on the full token sequence of a reference video — not a fixed embedding — learning to extract and reproduce static attributes (facial geometry, texture) and dynamic behavioral patterns (talking rhythm, micro-expressions) through attention over the full reference context.
- **Sparse Reference Attention**: an asymmetric attention mechanism achieving linear-complexity conditioning on arbitrarily long reference videos, making full-sequence conditioning practical at production scale.
- **Production Pipeline**: five-stage training (flow matching pre-training → personality SFT → two-phase distillation >10× acceleration → RLHF alignment), a data engine curating 100M+ clips from 50M raw videos with cross-clip identity connectivity, and distributed inference across thousands of GPUs generating 1080p at unlimited duration.

## Method
Avatar V uses a video DiT backbone where Sparse Reference Attention processes the full reference video token sequence with asymmetric attention weights, enabling the model to attend to arbitrary-length references without quadratic cost. A dedicated motion representation stream captures individual-specific motion style (talking rhythm, head motion patterns) through an auxiliary motion branch, enabling closed-loop style transfer. An identity-aware super-resolution refiner recovers facial detail at 1080p by inheriting the full reference conditioning. Long-form generation uses chunk-based inference with a Ref2V+Prefix2V strategy and a global appearance anchor for temporal consistency. Additional components include context-level KV caching and sparse validity masking for efficient inference.

## Why It Matters
Avatar video generation is central to digital humans, virtual assistants, content creation, and entertainment. Capturing behavioral identity — not just appearance — from video references marks a qualitative advance: Avatar V's ability to reproduce an individual's unique talking rhythm and gestural tendencies, at production quality surpassing the leading commercial systems, establishes a new frontier for personalized human video generation.

### [2606.14162](https://arxiv.org/abs/2606.14162) — VideoWeave: Unlocking Geometric Consistency in Video Generation via Joint Geometry-Video Modeling
**Score: 84/100** | Video Generation + 3D

**Authors:** Xunzhi Xiang, Zixuan Duan, Yabo Chen, Zhengxuan Wei, Guiyu Zhang, Zixiao Gu, Zhe Gao, Haibin Huang, Chi Zhang, Qi Fan, Xuelong Li

## TL;DR
VideoWeave is a latent-space post-training framework that improves 3D geometric consistency in video generation by jointly denoising implicit geometry-model features alongside video latents — without explicit geometry reconstruction — then discarding the geometry branch entirely at inference for zero overhead.

## Problem
Large-scale video diffusion models fail to maintain 3D structure over time because they are trained on 2D video without reliable geometric priors, causing depth drift and implausible motion under viewpoint changes. Existing approaches enforce consistency via explicit geometry reconstructions (depth maps, point clouds) that propagate upstream errors and add computational overhead.

## Key Contributions
- **Implicit Geometry Latent Adaptation**: adapts internal features from a pretrained geometry model into "geometry latents" in the video diffusion latent space, providing flexible non-rigid guidance that tolerates reconstruction errors, without decoding explicit geometry outputs.
- **Geometry-Video Joint Diffusion**: co-denoises geometry latents and video latents as a unified variable in a shared diffusion space, allowing 3D structure to shape the generative distribution during training while being fully discarded at inference.
- **GeoVid-80K Dataset**: an 80K-video dataset curated for rich depth cues, motion parallax, and viewpoint changes, providing paired appearance and implicit geometry representations for learning 3D-aware generative priors.

## Method
VideoWeave proceeds in three stages. First, Geometry Latent Adaptation projects geometry-model internal features into the diffusion latent space without modifying the original video prior (geometry warm-up). Second, Geometry-Video Joint Diffusion adds geometry latents as co-denoised tokens in the shared diffusion process, training the joint model on GeoVid-80K. Third, Joint-Distribution Distillation compresses the joint model into a compact student video generator that internalizes geometric priors — at inference, no geometry branch is needed. The key insight is to treat geometry as a "training-time companion" latent rather than an explicit condition or supervision target.

## Why It Matters
3D geometric consistency is the critical bottleneck for using video generation in world simulation, autonomous driving, and embodied AI applications. VideoWeave's approach removes the dependency on explicit reconstruction pipelines and adds no inference overhead, making it a practical post-training technique that can be applied on top of any existing video diffusion model to unlock geometry-aware generation.

### [2606.13707](https://arxiv.org/abs/2606.13707) — Orchestra-o1: Omnimodal Agent Orchestration
**Score: 82/100** | Agentic AI

**Authors:** Fan Zhang, Vireo Zhang, Shengju Qian, Haoxuan Li, Hao Wu, Jinyang Wu, Donghao Zhou, Zhihong Zhu, Zheng Lian, Xin Wang, Pheng-Ann Heng

## TL;DR
Orchestra-o1 is an omnimodal agent orchestration framework that enables multi-agent systems to coordinate across text, image, audio, and video modalities through unified modality-aware task decomposition and parallel sub-agent execution, surpassing the best existing approach by 10.3% on OmniGAIA and achieving SOTA among open-source omnimodal agents with a fine-tuned 8B model via DA-GRPO.

## Problem
Existing LLM-based agent frameworks handle only text or vision-language tasks, but real-world scenarios require simultaneous understanding and coordination of text, image, audio, and video. Native omnimodal models that process all modalities in a single model struggle with long-horizon reasoning and cross-modal tool use, while existing orchestration frameworks lack support for heterogeneous multi-modal tasks.

## Key Contributions
- **Orchestra-o1 Framework**: a unified omnimodal orchestration system with modality-aware task decomposition, online sub-agent specialization (image/audio/video/code sub-agents), parallel sub-task execution, and context memory for iterative refinement — enabling a single framework to handle text, image, audio, and video tasks together.
- **Decision-Aligned GRPO (DA-GRPO)**: an agentic RL training approach that rewards high-quality orchestration decisions (task decomposition, sub-agent allocation, result integration) rather than only final output correctness, training Orchestra-o1-8B to SOTA among open-source omnimodal agents.
- **Theoretical advantage**: proves that orchestration-based approaches offer strictly higher task coverage than native omnimodal agents under any fixed model budget, due to modular specialization.

## Method
Orchestra-o1 uses a main LLM orchestrator that decomposes an omnimodal task into modality-specific sub-tasks based on input type. Sub-agents with appropriate tools (image analysis, audio analysis, video analysis, web search, code execution) execute sub-tasks in parallel; context memory aggregates results for iterative refinement. DA-GRPO trains the orchestrator model using group-level policy gradient rewards derived from orchestration decision quality — not just final answer correctness — enabling the 8B model to learn when to decompose, which sub-agents to call, and how to integrate heterogeneous results. Code and model released on GitHub and HuggingFace.

## Why It Matters
Real-world agentic tasks are inherently omnimodal — research assistants analyze papers (text, figures, equations), multimedia agents handle video and audio alongside text. Orchestra-o1 demonstrates that open-source orchestration frameworks with proper multi-modal tool ecosystems and RL-trained orchestration policies can surpass proprietary omnimodal systems (Gemini-3-Pro: 62.5% vs. Orchestra-o1: 72.8% on OmniGAIA), pointing toward scalable open-source omnimodal agent systems.
