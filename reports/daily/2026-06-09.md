### 1. VideoWeaver: Evaluating and Evolving Skills for Agentic Long Video Generation
**Score: 98/100** | [2606.08091](https://arxiv.org/abs/2606.08091)
**Jianhui Wei, Jie Tan, Hengchuan Zhu, Xiaotian Zhang, Yan Zhang, Ziyi Chen, Daoan Zhang, Wei Xu, Zuozhu Liu** (Zhejiang University, ByteDance)

## TL;DR
VideoWeaver is a benchmark and agent harness for long video generation where an agent composes and evolves its own skill workflows to turn a single instruction into a long video — systematically evaluating whether general-purpose coding agents (Claude Code, Codex) can handle this long-horizon multimodal task.

## Problem
General-purpose agent frameworks excel at tool use and orchestration, but their ability to handle long video generation — requiring narrative planning, multi-modal reference coordination, and temporal consistency across many clips — has not been systematically studied. Existing agentic video systems use hardcoded pipelines rather than letting agents build their own.

## Key Contributions
- VideoWeaver benchmark: 16 task categories, 285 cases with multimodal references spanning text, image, audio, and video combinations
- Agent-as-judge evaluation metric that inspects both the execution trace and the final video, grounding scores in intermediate metadata and files — aligns closely with human judgments, especially on process metrics
- Skill evolution algorithm that refines and merges agents' own skills through agent-as-judge feedback, with explicit skill composition shown to outperform using foundation skills alone

## Method
Rather than following predefined pipelines, agents compose foundation skills into their own workflows for each task. The benchmark covers tasks including cinematic storytelling, personalized vlogs, music videos, and animation across 16 categories. The agent-as-judge evaluates both process (execution trace quality) and output (final video quality). The evolution algorithm uses this feedback to iteratively merge and refine composition skills, improving quality across multiple agent frameworks and backbone models.

## Why It Matters
This is the first systematic study of whether general-purpose coding agents — the same frameworks used for software tasks — can be directly applied to long-form video production. The benchmark, evaluation protocol, and evolution framework together define a research agenda at the intersection of agentic AI and video generation, with released code and dataset to enable community follow-up.

### 2. Crayotter: Traceable Multi-Agent Workflows for Long-Form Video Editing
**Score: 92/100** | [2606.07636](https://arxiv.org/abs/2606.07636)
**Lecheng Yan, Yichong Zhang, Ben Pan, Xiaoyu Zheng, Jiawei Qian, Anqi Wu, Wenxi Li, Chenyang Lyu** (Crayotter Project)

## TL;DR
Crayotter is an open-source multi-agent system for prompt-driven long-form video editing that externalizes inspectable artifacts at every production phase (material preparation → editing research → timeline execution), enabling targeted repair of failed segments instead of full restarts — scoring 3.40/5 vs 2.44 and 1.70 for competing baselines in human evaluation.

## Problem
Editing a long-form video from heterogeneous footage requires coordinating narrative intent, asset retrieval, timeline construction, transitions, narration, and post-production across many steps. Existing AI editing systems produce black-box results: when something fails, there is no way to diagnose which step went wrong or revise it selectively.

## Key Contributions
- Three-phase architecture: coverage-aware material preparation, artifact-based editing research (Deep Editing Research), and tool-grounded timeline execution — each phase externalizing a structured, inspectable artifact chain
- Selective segment revision: agents can diagnose and re-run only the failed timeline segment without restarting the entire editing run
- Trajectory-level RLVR design with a replayable trajectory schema and verifiable reward, preparing workflows for future policy optimization

## Method
Phase 1 retrieves and prepares footage via coverage-aware search. Phase 2 conducts deep analysis of clips, building multimodal editing blueprints. Phase 3 executes the timeline with tool calls (cuts, transitions, narration, subtitles, audio). All phases produce inspectable artifacts. A ReAct-style editing trajectory makes the run fully reproducible. Human evaluation on 23 themes against CapCut-Mate (2.44/5) and CutClaw (1.70/5) shows consistent gains in theme alignment, narrative coherence, and editing smoothness.

## Why It Matters
Advances multi-agent video production by making workflows transparent and diagnostically repairable; the RLVR-ready trajectory schema creates a direct path from current multi-agent editing to future learned policies. Directly relevant to both agentic AI workflows and long-form video generation research.

### 3. ViMax: Agentic Video Generation
**Score: 91/100** | [2606.07649](https://arxiv.org/abs/2606.07649)
**Lingxuan Huang, Sizhe He, Hengji Zhou, Liqiang Nie, Lianghao Xia, Chao Huang** (HKU, SCUT, HIT Shenzhen)

## TL;DR
ViMax is a multi-agent video generation framework that addresses long-form video creation through hierarchical narrative planning with retrieval-augmented generation and a dependency-aware visual consistency mechanism, maintaining character and environmental coherence across multi-scene timelines.

## Problem
Current video generation models produce only short clips and suffer "catastrophic semantic forgetting" when extended — character identity, world geometry, and physical laws drift across shots unpredictably, breaking narrative immersion. Streaming methods extend duration but cannot handle multi-scene narratives; consistency mechanisms don't scale to full-length stories.

## Key Contributions
- Hierarchical narrative engine with retrieval-augmented generation for global story coherence across temporal boundaries
- Dependency-aware visual consistency mechanism using a graph-based structure that tracks character and environmental states across scenes
- Coordinated multi-agent collaboration where specialized VLM-guided agents continuously monitor and refine both narrative coherence and visual fidelity; spatial coherence maintained via transition video generation

## Method
ViMax hierarchically decomposes a narrative into scenes and shots, with RAG providing global context awareness so each shot is generated with awareness of the full story arc. A dependency graph tracks object/character appearances across shots to enforce visual consistency. Multiple specialized agents negotiate narrative decisions, visual continuity, and production quality concurrently. Transition videos bridge scenes to enforce spatial coherence.

## Why It Matters
Provides a complete agentic system for long-form video creation from a single narrative prompt; directly addresses the scaling bottleneck of current video generation models through principled multi-agent coordination. The framework's design is generalizable to other long-horizon multimodal generation tasks.

### 4. CineDance: Towards Next-Generation Multi-Shot Long-Form Cinematic Audio-Video Generation
**Score: 91/100** | [2606.09639](https://arxiv.org/abs/2606.09639)
**Yuheng Chen, Teng Hu, Yuji Wang, Qingdong He, Zhucun Xue, Qianyu Zhou, **Xiangtai Li**, Lizhuang Ma, Jiangning Zhang, Dacheng Tao** (SJTU, UESTC, ZJU, Tokyo, NTU)

## TL;DR
CineDance introduces CineDance-1M — a 1M-video open-research dataset averaging 92.8 seconds and 24.2 shots per video with hierarchical dual-modal annotations — along with CineBench for evaluation, addressing the data scarcity bottleneck for multi-shot long-form cinematic audio-video generation. Notable: **Xiangtai Li** (close collaborator) is a co-author.

## Problem
Open-source video generation models lag commercial systems (Sora, Veo) on cinematic narrative generation because they lack large-scale, structured training data with multi-shot continuity and synchronized audio-video annotations. No public dataset combines long-form content, shot-level narrative structure, and dual-modal (audio + video) captioning at scale.

## Key Contributions
- CineDance-1M: 1M audio-video sequences averaging 92.8s and 24.2 continuous shots per video, curated via a three-stage pipeline (diverse sourcing + cleansing, film-theory-inspired narrative parsing, hierarchical dual-modal captioning)
- CineBench: six-dimensional, human-aligned benchmark for complex narrative audio-video evaluation with a diverse prompt suite
- CineDance model: adapts LTX-2.3 with reference frames as training-time scaffolds for multi-shot subject and environment consistency, validating the dataset quality

## Method
Data curation: diverse video sourcing → comprehensive cleansing → bottom-up narrative sequence parsing via state-based shot grouping → configurable structured dual-modal annotation for audio and video. The resulting 92.8s average clips have 24.2 narrative-coherent shots each. CineDance model uses reference frames to scaffold multi-shot generation with temporal consistency.

## Why It Matters
Removes the data bottleneck for open-source cinematic video generation; the dataset and benchmark will enable the community to train and evaluate models that match commercial-grade narrative consistency. Notable: **Xiangtai Li** co-authored this work on open-source cinematic video data and generation.

### 5. TIDE: Task-Isolated Diffusion for Unified Video Editing and Generation
**Score: 88/100** | [2606.08260](https://arxiv.org/abs/2606.08260)
**Qi Liu, Gang Yue, Mingyu Yin, Lisai Zhang, Yidi Wu, Yaole Wang, Yaohui Wang, Chang Yao, Jingyuan Chen, Lin Ma** (Zhejiang University, Bilibili Inc.)

## TL;DR
TIDE unifies instruction-based editing, reference-guided editing, and multi-reference generation under a single Diffusion Transformer by assigning per-token task embeddings that explicitly tell the model the role of each conditioning token, achieving state-of-the-art across all three tasks without task-specific architectures.

## Problem
Video generation and editing capabilities are handled by separate task-specific models. Existing unified attempts either need dedicated auxiliary encoders or lack mechanisms to disambiguate heterogeneous conditioning tokens (target vs. source vs. reference), causing cross-task interference especially when the number and type of visual conditions vary.

## Key Contributions
- Per-token task embeddings: each input token receives a task-specific identifier that explicitly disambiguates target/source/reference roles, enabling the model to correctly handle varying conditioning across tasks
- Dual-path conditioning: couples a vision-language model for high-level semantic understanding with a VAE latent path for fine-grained structural fidelity
- Multi-task progressive training strategy that incrementally introduces tasks by increasing complexity, harmonizing diverse objectives and enabling smooth cross-task generalization

## Method
All three video tasks are cast as conditional denoising with varying token roles. Per-token embeddings replace implicit positional/structural disambiguation. Dual-path conditioning provides complementary signals (semantics from VLM, structure from VAE). Progressive training prevents earlier tasks from interfering with later, more complex ones. Extensive experiments show TIDE achieves SOTA across all evaluated benchmarks.

## Why It Matters
Demonstrates a clean, principled architectural solution to multi-task video generation: per-token role disambiguation scales to arbitrary conditioning configurations without dedicated encoders. This approach should generalize to future video tasks.

### 6. CP4D: Compositional Physics-aware 4D Scene Generation
**Score: 86/100** | [2606.09187](https://arxiv.org/abs/2606.09187)
**Hanxin Zhu, Cong Wang, Tianyu He, Long Chen, Xin Jin, Chen Gao, Zhibo Chen**

## TL;DR
CP4D generates physically plausible 4D scenes (dynamic 3D) by decomposing them into static backgrounds and dynamic foreground objects, using a hybrid motion synthesis strategy that combines physics simulators (MPM, rigid collision, position-based dynamics) with video diffusion model priors for realistic, physically grounded dynamics.

## Problem
Existing 4D generation approaches produce physically inconsistent and visually implausible results — objects interpenetrate, defy gravity, and exhibit unrealistic motion — because they do not model underlying physical principles during generation.

## Key Contributions
- Three-stage pipeline: 3D representation synthesis for background and foreground objects → physics-grounded motion simulation → automated composition of coherent 4D scenes
- Hybrid motion synthesis strategy integrating multiple physical simulators (MPM for elastic/fluid, rigid collision, position-based dynamics) with video diffusion model priors for realistic object interactions
- Automated composition mechanism that optimizes spatial placement and seamlessly fuses static environments with dynamic objects via relative spatial attributes and optimization-based refinement

## Method
Stage 1 uses pretrained expert models to generate 3D representations separately for backgrounds and foregrounds. Stage 2 simulates motion with physics solvers to ensure physical plausibility, then refines with video diffusion model priors to add visual realism. Stage 3 uses automated spatial optimization to compose the static environment and dynamic objects into coherent, viewable 4D scenes with diverse camera viewpoints.

## Why It Matters
Bridges physics-based simulation with neural 4D generation to produce scenes that are both visually realistic and physically sound; enables applications in AR/VR, robotics, and world models requiring physically plausible dynamic environments.

### 7. Struct-Searcher: Agentic Structural Thinking Advances Multimodal Deep Information Seeking
**Score: 84/100** | [2606.07689](https://arxiv.org/abs/2606.07689)
**Fan Zhang, Vireo Zhang, Shengju Qian, Haoxuan Li** et al.

## TL;DR
Struct-Searcher is a plug-and-play agentic workflow grounded in belief revision theory that maintains an evolving multimodal structural graph to resolve conflicting evidence during deep information seeking, achieving an average +17.2% relative accuracy improvement on BrowseComp-VL across five backbone models.

## Problem
Existing deep research agents use linear evidence accumulation without principled mechanisms for handling contradictory information across heterogeneous modalities — leading to inconsistent conclusions when text and visual evidence conflict. As information seeking shifts from text-only to multimodal settings, this gap becomes critical.

## Key Contributions
- Structural agentic workflow grounded in belief revision theory: maintains an evolving multimodal structural graph throughout the reasoning process, not just a flat accumulation of evidence
- Conflict-aware multimodal information seeking that explicitly detects and resolves contradictions across modalities as the graph evolves
- Plug-and-play, model-agnostic design: +17.2% on BrowseComp-VL (5 backbones), +3.7% on MM-BrowseComp, +1.5% on HLE-VL over previous SOTA without retraining

## Method
Struct-Searcher represents the agent's world knowledge as a structural graph where nodes are claims and edges represent logical or evidential relationships. As new evidence arrives, belief revision theory guides updates that can retract conflicting nodes rather than blindly appending. This structural approach enables tracking of claim provenance and principled conflict resolution across text and visual modalities.

## Why It Matters
Provides a principled solution to a fundamental limitation of current research agents: handling contradictory multimodal evidence. The plug-and-play property means this can immediately improve any deep research agent without architectural changes — directly advances agentic AI for information seeking and scientific research.

### 8. SceneConductor: 3D Scene Generation from Single Image with Multi-Agent Orchestration
**Score: 83/100** | [2606.08402](https://arxiv.org/abs/2606.08402)
**Jeonghwan Kim, Yushi Lan, Yongwei Chen, Hieu Trung Nguyen, Chuanyu Pan, Xingang Pan** (NTU, Oxford, Meshy AI)

## TL;DR
SceneConductor generates complete 3D scenes from a single image through a three-stage multi-agent orchestration framework — initialization, environment construction, and multi-agent refinement — where a planner agent routes simple fixes directly and dispatches specialist agents for complex localized revisions, consistently outperforming prior methods on geometric accuracy and perceptual realism.

## Problem
Single-image 3D scene generation requires inferring globally consistent geometry, spatial layouts, object relationships, and environmental context from ambiguous evidence. Holistic pipelines entangle factors and require extensive supervision; object-centric alternatives rely on domain-restricted layout modules that don't generalize to in-the-wild images.

## Key Contributions
- Three-stage multi-agent framework: scene initialization (object masks → 3D representations → initial layout), environment construction (scaffolding surfaces/materials/illumination), multi-agent refinement (planner + specialist agents)
- Geometry-aware layout predictor trained on sparse point-map priors, enabling robust generalization from segmentation-level data without scene-level annotations
- Planner agent that identifies structural/visual inconsistencies, applies simple corrections directly, and routes complex revisions to appropriate specialist agents

## Method
Initialization extracts object masks and builds coarse object-level 3D representations with initial spatial layout. Environment construction uses point-map geometry to scaffold supporting surfaces, room boundaries, materials, and illumination. In refinement, a planner agent assesses the scene and either fixes issues directly or dispatches specialist agents for complex localized revisions reintegrated into the global scene. This modular design avoids the memory/compute scaling problem of holistic scene generators.

## Why It Matters
Combines agentic orchestration with 3D reconstruction/generation for a scalable, generalizable single-image scene completion system; the specialist-agent routing pattern is directly applicable to other complex 3D generation tasks.

### 9. Ultra Flash: Scaling Real-Time Streaming Video Generation to High Resolutions
**Score: 82/100** | [2606.09150](https://arxiv.org/abs/2606.09150)
**Luxury, Jie Huang, Zihao Fan, Xiaoxiao Ma** et al. (JD Explore Academy, USTC, PKU, THU)

## TL;DR
Ultra Flash achieves real-time high-resolution video generation — ~30 FPS at 1080P and ~18 FPS at 2K on a single GPU — by cascading a low-resolution streaming model with a causal latent upsampler trained via hybrid-reward distillation and streaming preference optimization, removing the resolution ceiling from autoregressive video diffusion.

## Problem
Autoregressive video diffusion models achieve good streaming quality but are limited to low resolutions (e.g., 480P). Pixel-space super-resolution approaches are too slow for real-time use; efficient high-resolution video generation at interactive frame rates remains an open challenge.

## Key Contributions
- Architecture-preserving T2V-to-TV2V super-resolution training paradigm with AIGC-oriented data degradation that preserves the base model's generative capability while enabling high-resolution cascading on top of any existing streaming model
- Causal streaming latent upsampler paired with a high-resolution decoder, enabling efficient spatiotemporal upsampling in latent space with negligible overhead
- Cascade optimization scheme: hybrid-reward sparse causalization + single-step distillation of the SR model, then cascaded streaming self-forcing preference optimization with dynamic cache management

## Method
Ultra Flash trains a latent-space upsampler on top of an existing low-resolution streaming model without modifying the base model. The upsampler learns to super-resolve latents causally (each frame only attends to past frames). Single-step distillation reduces inference cost. Streaming self-forcing preference optimization uses DPO-style training to improve coherence across long sequences. Dynamic cache management maintains low latency.

## Why It Matters
Removes the resolution bottleneck from real-time streaming video generation; the architecture-preserving, cascade-compatible design means Ultra Flash can plug on top of any current or future streaming model, making it broadly applicable to the video generation ecosystem.

### 10. MilliVid: Hierarchical Latents for Long-Range Consistency in Video Generation
**Score: 82/100** | [2606.09056](https://arxiv.org/abs/2606.09056)
**Ishaan Preetam Chandratreya, David Charatan, Basile Van Hoorick, Sergey Zakharov, Vitor Guizilini, Phillip Isola, Vincent Sitzmann** (MIT, Toyota Research Institute)

## TL;DR
MilliVid addresses long-range consistency in video generation by using a hierarchical autoencoder that encodes frames into multi-scale token pyramids, then performs coarse-to-fine generation rollout so that coarse (layout/semantics) context persists globally across the entire video while fine-grained texture is refreshed locally.

## Problem
Video generative models lose long-range consistency because context windows can't hold enough frames at full resolution; increasing context length scales quadratically. Token-efficient approaches like FramePack also fail to recall objects that leave and re-enter the camera frame, even when compressed context is available.

## Key Contributions
- Hierarchical autoencoder that compresses each frame into a pyramid of tokens: coarsest levels encode scene layout and semantics (few tokens per frame), finest levels add high-frequency appearance and texture (many tokens per frame)
- Coarse-to-fine generation rollout: the diffusion model generates tokens at each level using the corresponding hierarchical latents as context, with coarse-level context maintained over long spans while fine-level context is kept short-range
- Validated on long Minecraft videos, producing substantially more consistent rollouts than FramePack and other baselines in geometry and object permanence

## Method
Pre-train a hierarchical VAE that encodes frames at multiple compression levels. Train a video diffusion model to generate in this hierarchical space using coarse-to-fine rollout: coarsest tokens serve as long-range context (scene-level consistency), finer tokens serve as short-range context (texture details). This decouples "what objects are where" from "how they look in detail", enabling theoretically unbounded sequence length while maintaining scene-level coherence.

## Why It Matters
Provides a principled, architecture-level solution to long-range consistency in video generation by aligning token resolution with the temporal persistence required at each detail level — a fundamental insight that should influence future long-form video model design.

### 11. A Case Study of Evaluating AI Agents on a Neuroscience Data-to-Discovery Pipeline
**Score: 81/100** | [2606.07718](https://arxiv.org/abs/2606.07718)
**Kai A. Horstmann, Ethan Lin, Alice A. Robie, Jennifer J. Sun** et al.

## TL;DR
This empirical study evaluates general-purpose coding agents on a realistic fly optogenetics data-to-discovery pipeline — with datasets orders of magnitude larger than typical benchmarks — finding that agents can handle individual stages but fail end-to-end, and identifying scientific judgment and computational resource management as the key unsolved challenges.

## Problem
Agentic AI tools are promised to automate scientific research pipelines, but existing benchmarks use small datasets and predefined success criteria, not the open-ended, domain-expert-grounded evaluation that real science requires. Whether agents can handle actual scientific workflows is unknown.

## Key Contributions
- Empirical evaluation on a fly optogenetics data-to-discovery pipeline with tasks substantially larger than existing benchmarks and evaluation criteria grounded in domain expert standards
- Identification of the critical failure mode: agents struggle most when no predefined iteration criterion exists and they must apply scientific judgment to assess their own intermediate outputs
- Distillation of principles for constructing scientific agent tasks and rigorous evaluation criteria for open-ended scientific problems

## Method
Agents are assessed on individual pipeline stages and end-to-end completion of a fly optogenetics analysis pipeline. Code iteration analysis identifies where agents struggle. Agents attempt visual inspection of intermediate outputs for self-evaluation but largely fail to correctly interpret what they see. Challenges include computational resource management, generalization to held-out data, and cross-stage error accumulation.

## Why It Matters
Provides grounded evidence about current AI agent capabilities for real-scale scientific workflows; the specific failure modes identified — scientific judgment without predefined criteria, visual self-assessment, resource management — define the open research frontier for AI scientist systems and automated scientific discovery.

### 12. PhysAgent: Automating Physics-Based 4D Synthesis via Trajectory-Grounded Multi-Agent Feedback
**Score: 80/100** | [2606.08688](https://arxiv.org/abs/2606.08688)
**Chunji Lv, Jiaxi Ye, Yuchen Jiang, Rexar Lin, Changsheng Li** (Beijing Institute of Technology)

## TL;DR
PhysAgent is the first simulator-in-the-loop multi-agent framework for automated physics-based 4D synthesis, eliminating manual force field configuration by using a Semantic Agent for initialization and Trajectory-Grounded Refine Agents that extract dense point trajectories from rendered frames to drive LLM-based zero-shot force field optimization.

## Problem
Physics-based 4D synthesis requires manually configuring complex force fields — a severe bottleneck for large-scale simulation data generation. Naive LLM automation lacks physical feedback and causes inaccuracies; SDS-based approaches suffer from sluggish gradients, local optima, and cannot dynamically switch discrete force fields.

## Key Contributions
- Simulator-in-the-loop multi-agent paradigm with a Semantic Agent equipped with an externalized Force Field Skill Library that generates valid initializations from arbitrary text/image/video prompts
- Trajectory-Grounded Refine Agents that extract dense point trajectories from rendered simulation frames, convert them to structured text descriptors, and use LLM commonsense reasoning for zero-shot macroscopic optimization leaps
- Full decoupling of intrinsic materials from extrinsic force fields, enabling dynamic switching of discrete force fields and escape from local optima

## Method
PhysAgent decouples material properties (handled by existing methods) from force field configuration (automated by PhysAgent). The Semantic Agent generates initial force configurations using a pre-built skill library. The Material Point Method (MPM) simulator runs physics. Refine Agents extract trajectories from rendered frames, describe deviations in structured text, and use LLMs to generate improved force configurations — closing the loop until physical plausibility is achieved.

## Why It Matters
Fully automates physics-based 4D synthesis for the first time; the simulator-in-the-loop, trajectory-grounded feedback approach demonstrates how agentic AI can be grounded in physical simulation feedback for reliable generation — a template for similar approaches in graphics, robotics, and world models.
