## Top Picks (Score ≥ 80)

### 1. S-Agent: Spatial Tool-Use Elicits Reasoning for Spatial Intelligence
**Score: 91/100** · [arXiv:2606.20515](https://arxiv.org/abs/2606.20515)  
**Authors:** Yalun Dai, Hao Li, Shulin Tian, Runmao Yao, Yuhao Dong, Fangzhou Hong, Zhaoxi Chen, Fangfu Liu, Baoliang Tian, Dingwen Zhang, Tao Wang, Kim-Hui Yap, Ziwei Liu  
**Project page:** [Ropedia/S-Agent](https://github.com/Ropedia/S-Agent)

## TL;DR
S-Agent is an agentic paradigm that turns VLMs into semantic planners for 3D spatial reasoning over multi-view images and videos: instead of static, frame-level inference, the agent iteratively requests geometric evidence via a three-level spatial tool hierarchy, maintains dual memory (Scene Memory for persistent 3D state, Agent Memory for reasoning history), and accumulates spatio-temporal evidence until it can answer the query. Training-free, it improves GPT-5.4 on MMSI-Bench by 4.5%; fine-tuning on its generated S-300K trajectories yields S-Agent-8B, which matches GPT-5.4 and Gemini 3 Pro despite being a compact 8B model.

## Problem
Current VLMs perform spatial reasoning as isolated, stateless inference over single frames or image pairs — they lack the ability to maintain persistent object identities across viewpoints, integrate geometric evidence over time, or build a coherent 3D scene model from partial, transient 2D observations. This creates a fundamental semantic-to-geometric gap: VLMs reason from lossy semantic priors rather than grounded 3D geometric evidence, making multi-view and video spatial reasoning unreliable.

## Key Contributions
- **Spatial Tool Hierarchy (3 levels):** Level 1 — 2D perception tools (frame selection, object grounding, open-vocabulary detection); Level 2 — 2D-to-3D geometric lifting (depth, metric coordinates, camera poses, bird's-eye-view); Level 3 — spatial knowledge aggregation experts (counting, measurement, orientation, relative position). Each level's outputs are reused across reasoning steps.
- **Dual Memory System:** Scene Memory tracks grounded entities and derived spatial facts across frames (entity-centric, question-conditioned persistent 3D state); Agent Memory records the reasoning trajectory (tool calls, observations, failures, intermediate conclusions) to prevent redundant evidence requests and enable iterative strategy refinement.
- **S-300K Trajectory Distillation → S-Agent-8B:** Zero-shot S-Agent trajectories on SenseNova-SI-800K are filtered, decomposed, and used for SFT of Qwen3-VL-8B, yielding S-Agent-8B that achieves 41.6% on MMSI-Bench (+10.5 pp over base Qwen3-VL-8B) and matches advanced closed-source models.

## Method
At each reasoning step, a tool-calling VLM planner receives the question, all input observations, the current Scene Memory (grounded entities + derived spatial facts), and Agent Memory (the reasoning trajectory). It emits an evidence request — selecting a tool or expert from the three-level hierarchy — and receives an observation that simultaneously updates both memories via Merge (Scene Memory consolidates reusable spatial evidence with deduplication) and Append (Agent Memory logs the procedural context). The agent iterates until accumulated evidence suffices to answer the query. This separates semantic planning (what evidence do I need?) from spatial evidence acquisition (tool execution), eliminating the need for the VLM to perform unreliable metric reasoning in free-form text.

## Why It Matters
S-Agent directly operationalizes the key missing ingredient in current spatial VLMs — stateful evidence accumulation over continuous 3D observations — using a training-free, model-agnostic framework. The finding that a compact 8B model fine-tuned on auto-generated S-Agent trajectories matches frontier models (GPT-5.4, Gemini 3 Pro) on spatial benchmarks is a strong data point that structured agentic reasoning scaffolds, not just scale, can close the gap. The framework architecture — planner + tool hierarchy + dual memory — is a generalizable pattern for any embodied or spatial reasoning agent, directly relevant to agentic AI research (#1 priority).
