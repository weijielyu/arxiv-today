### OmniReasoner: Thinking with Long Audio-Video via Native Tool Use

**Score: 90/100** · [arXiv:2607.19339](https://arxiv.org/abs/2607.19339)

**Authors:** Yu Chen, Caorui Li, Ziyu Xiong, Yidong Wang, Mingqi Gao, Shuman Liu, Biao Liu, Chunfeng Yang, Anxiang Zeng, Haibo Zhang, Chaofan Chen

## TL;DR
A post-training framework that teaches omnimodal LLMs to invoke a "zoom-in" tool on targeted temporal segments during long audio-video reasoning, achieving better accuracy while spending compute only where evidence is dense—trained via SFT + reinforcement learning, no manual annotation required.

## Problem
Long audio-video reasoning is hard because decisive evidence is sparse, cross-modal, and too expensive to preserve at uniformly high fidelity. Existing video-language models process entire streams at fixed granularity, wasting computation on uninformative segments while potentially missing fine-grained cues in crucial moments. The challenge is teaching a model to decide *when* and *where* to look more closely, rather than brute-forcing everything at once.

## Key Contributions
- **Native tool-use post-training**: Omnimodal LLMs are trained (via SFT then RL) to autonomously decide when to call a temporal zoom-in tool that retrieves high-fidelity excerpts from specified time windows—the first such agentic framework for long audio-video reasoning.
- **TimeAnchor**: A temporal consistency mechanism bridging low-resolution global previews with high-resolution local inspections, ensuring frame indices remain coherent across different sampling granularities.
- **Temporal Augmented Data Engine**: Automatically synthesizes tool-use training trajectories through video editing and composition, removing the need for costly human annotation of when tools should be called.

## Method
OmniReasoner starts from an omnimodal LLM that receives a compressed video preview as context. During inference, the model emits a structured tool call specifying a temporal window; the system retrieves a high-resolution clip from that window and feeds it back into the context. Training has two stages: supervised fine-tuning on synthetic trajectories generated by the data engine, then reinforcement learning from answer-correctness reward signals. TimeAnchor handles the translation between global and local frame indices so tool calls remain temporally grounded regardless of preview resolution.

## Why It Matters
This directly addresses the efficiency-quality trade-off in long-form video understanding. Rather than uniformly scaling up context windows (prohibitively expensive), OmniReasoner teaches selective attention—the approach mirrors how humans skim a video then rewatch key moments. The RL training loop and data engine together make this practical without requiring expensively annotated tool-use supervision data. Directly relevant to priority 1 (agentic AI systems with tool use) and priority 2 (video understanding/generation). Code: https://github.com/RockyChen0205/OmniReasoner

### FilmWorld: Agentic Novel-to-Film Generation through Dynamic Cinematic World Modeling

**Score: 88/100** · [arXiv:2607.19038](https://arxiv.org/abs/2607.19038)

**Authors:** Jialong Zuo, Haotong Zuo, Shiwei Zhang, Xiang Wang, Chen Li, Nong Sang, Changxin Gao, Xiang Bai

## TL;DR
FilmWorld decomposes novel-to-film generation into a multi-agent pipeline with explicit world state tracking—Construction agents build a stateful cinematic blueprint before any rendering occurs; Evolution agents synthesize video while referencing pre-materialized state trajectories—achieving stable consistency across long, complex narratives at O(N/P) parallel latency.

## Problem
Translating novels into films requires synthesizing coherent, long-duration visual narratives across dozens of scenes where characters evolve, environments change, and causal plot threads must be maintained. Current video generation models produce only short, single-scene clips; naive chaining of such clips leads to entity drift (e.g., a character losing an injury between scenes) and no reliable mechanism for maintaining visual identity across scenes separated by many frames.

## Key Contributions
- **Dynamic Cinematic World Modeling**: Formalizes novel-to-film as world state management—entities (characters, locations, props) have explicit state identifiers with visual reference assets that persist and evolve under plot transitions, decoupling semantic consistency from sequential generation order.
- **Six-agent collaborative architecture**: Construction side (narrative translation, world entity state modeling with visual anchoring, state-driven shot planning) and Evolution side (state-anchored visual generation, cross-shot dynamic state propagation, closed-loop state verification) work in concert, enabling parallel synthesis with O(N/P) latency.
- **FilmEval benchmark**: 15 difficulty-graded novels with 9 automatic metrics across cinematic presentation, film consistency, and novel fidelity—with human evaluation confirming Spearman ρ=1.0 alignment.

## Method
Construction agents pre-materialize a complete state trajectory (offline) before any video is rendered. A "state identifier" system discretizes entity attributes into addressable symbols with associated visual reference images. Evolution agents then render shots by retrieving the pre-computed state for each scene rather than inferring it sequentially from previous outputs—eliminating error accumulation. A scene-local sliding window with dual conditioning (textual end-state constraints + visual keyframe guidance) enforces continuity without creating O(N) sequential dependencies. Closed-loop state verification corrects detected discrepancies after generation.

## Why It Matters
FilmWorld demonstrates that explicit world modeling is the missing ingredient for long-form video generation systems. By externalizing state into a structured symbol system rather than relying on implicit video-to-video conditioning, the framework maintains character consistency even across narratives with high complexity (ablation: removing world state collapses Character Consistency from 82.12 → 54.50). The 5.62× speedup from parallel synthesis is practically significant. This work sits squarely at the intersection of agentic AI (priority 1) and video generation (priority 2), showing how structured agent pipelines unlock capabilities that monolithic generation models cannot achieve.

### Latent Riemannian Flow Matching for Geometry-Grounded 3D Foundation Models

**Score: 82/100** · [arXiv:2607.19120](https://arxiv.org/abs/2607.19120)

**Authors:** Lisa Weijler, Irene Ballester, Guofeng Mei, Tolga Birdal, Pedro Hermosilla

**Project page:** https://lisaweijler.github.io/geometry-grounded-rfm/

## TL;DR
Flow matching performed directly in the frozen latent space of a 3D foundation model (VGGT), with a key insight that VGGT tokens live on a product of hyperspheres—not Euclidean space—requiring Riemannian flow matching with geodesic interpolation to avoid mode collapse; enables probabilistic 3D generation with strong geometric consistency from unposed sparse views.

## Problem
Geometric foundation models like VGGT provide strong deterministic 3D priors from unposed images but cannot hallucinate geometry beyond what input views directly support—they are inherently feed-forward with no generative capability. Conversely, pure generative 3D models lack explicit geometric structure, leading to multi-view inconsistencies. The gap: how to make a geometry-grounded foundation model generative without abandoning its learned 3D priors.

## Key Contributions
- **Manifold discovery**: VGGT's post-LayerNorm tokens form a product of four zero-mean hyperspheres (each of dimension C-2, C=2048)—the authors formally prove this and show that standard Euclidean flow matching forces probability paths through low-density interior regions, causing mode collapse.
- **Conditional Riemannian Flow Matching (RFM)**: A flow matching framework that respects the hyperspherical geometry via geodesic interpolation and parallel transport for the regression target, keeping trajectories on valid manifold regions.
- **Generative 3D reconstruction**: From sparse unposed input views, the model samples diverse plausible completions rather than a single deterministic prediction—enabling uncertainty quantification and scene editing through distribution sampling.

## Method
The approach trains a conditional velocity field over VGGT's frozen token space. During training, source noise is sampled on the product manifold, and geodesic interpolants between noise and VGGT-encoded clean tokens define training targets. The learned vector field respects manifold geometry (using Riemannian ODE solvers at inference). Conditioning on unposed context image tokens and target camera poses steers generation. VGGT's frozen DPT heads decode generated latents into depth/point maps; an additionally trained RGB decoder adds photometric quality.

## Why It Matters
This is a principled geometric insight—treating latent spaces as non-Euclidean—that generalizes to any foundation model whose tokens have LayerNorm constraints (a ubiquitous design choice). The 40%+ Chamfer distance reduction over Gen3R on ScanNet++ and ETH3D is substantial. For 3D reconstruction and generation (priority 4), this opens a new paradigm: rather than training generative models from scratch, inject probabilistic generation into existing deterministic foundation models by respecting their latent geometry.

### Generative World Renderer at the Speed of Play

**Score: 81/100** · [arXiv:2607.18703](https://arxiv.org/abs/2607.18703)

**Authors:** Guixu Lin, Zheng-Hui Huang, Siqi Yang, **Ming-Hsuan Yang**, Kaipeng Zhang, Zhixiang Wang

Notable: **Ming-Hsuan Yang** is a co-author.

## TL;DR
AlayaRenderer-Flash accelerates a G-buffer-conditioned generative world renderer from 0.56 FPS to 31.54 FPS through three co-designed optimizations—autoregressive streaming, few-step diffusion distillation (50→4 steps), and distilled tiny codecs—enabling fully playable AI-synthesized game worlds at real-time frame rates.

## Problem
Generative world renderers synthesize photorealistic RGB frames conditioned on structured G-buffers (depth, normals, albedo) from physics engines, enabling text-prompted real-time scene stylization while preserving gameplay logic. The original AlayaRenderer achieves high quality but runs at 0.56 FPS—over 50× too slow for interactive use—primarily due to 50-step denoising and expensive VAE encode/decode operations. The challenge is closing this gap while retaining quality, temporal consistency, and support for dynamic text prompts.

## Key Contributions
- **Autoregressive streaming**: Reformulates generation as a chunk-based autoregressive process with a three-tier temporal compression hierarchy (recent history full-fidelity → progressively coarser) supporting unbounded continuous rendering and mid-stream prompt updates.
- **Three-stage few-step distillation** (50→4 steps): Guidance distillation folds classifier-free guidance into weights; progressive step reduction provides stable initialization; Mean Flow Distillation under self-rollout conditions on the model's own predictions, with lightweight GAN heads recovering high-frequency detail.
- **Distilled tiny codecs**: A single shared G-buffer encoder replaces five separate VAE passes; a TAEHV-architecture temporal decoder replaces the full Wan VAE decoder—both distilled from frozen teachers, reducing remaining latency bottleneck.

## Method
During gameplay, the physics engine streams G-buffers and player inputs to the distilled encoder, producing compact latents. The 4-step diffusion transformer processes chunks autoregressively, maintaining persistent temporal state across chunk boundaries via the three-tier compression hierarchy. A text sink in self-attention allows dynamic style prompt updates. The tiny decoder streams output frames at 31.54 FPS, verified in a fully playable SuperTuxKart integration.

## Why It Matters
This technical report demonstrates that generative world rendering is now a viable real-time capability, not just an offline research exercise. The specific combination of streaming + few-step distillation + distilled codecs, each individually known but not co-designed, achieves a multiplicative speedup that crosses the real-time threshold. For video generation research (priority 2), the autoregressive streaming formulation and the Mean Flow Distillation approach are directly transferable to other video generation contexts. The real-world game integration provides concrete proof of utility.

### DeforM: Reasoning-Guided Physics-Aware Video Generation via Spatial-Temporal Masking

**Score: 80/100** · [arXiv:2607.18664](https://arxiv.org/abs/2607.18664)

**Authors:** Yunyi Li, Yu Qiao, Yaohui Wang, Xinyuan Chen

## TL;DR
DeforM uses a VLM to reason about which spatial regions undergo physical deformation (melting, squeezing, fracturing), generates spatial-temporal masks for those regions, then guides image-to-video generation to concentrate on physics-critical areas—via either training-free attention modulation or a trained dense mask modulator.

## Problem
Video generation models produce visually plausible but physically inaccurate deformation dynamics. Unlike rigid-body motion (describable by trajectories), complex deformations like melting or fracturing are difficult to specify. The core issue is a "semantic-spatial gap": abstract text prompts about physics fail to align with specific pixel locations, causing attention to dilute globally rather than concentrating on where physics actually happens—leading to soft deformations everywhere and accurate physics nowhere.

## Key Contributions
- **DeforM-Reason**: A VLM-guided physical reasoning module that identifies target objects undergoing deformation and generates spatial-temporal masks via open-vocabulary detection, decoupling semantic understanding from visual generation.
- **DeforM-Free**: Training-free attention modulation that amplifies cross-attention scores within masked physics-critical regions (focus scale α=1.4) without retraining the base video generation model—useful for rapid analysis.
- **DeforM-Injection**: A trained Dense Mask Modulator injecting learned feature offsets into both self-attention and cross-attention blocks with synchronized modulation, achieving superior deformation fidelity.

## Method
Given an initial image and text prompt, DeforM-Reason uses a VLM to identify which objects are physics-relevant, then uses an open-vocabulary detector to spatially ground them into binary masks aligned with video latents. At inference, the VLM performs temporal extrapolation to predict object trajectories over the full video duration. These masks guide generation: DeforM-Free scales attention scores within masked regions during inference only; DeforM-Injection trains a LoRA-adapted modulator with a region-sensitive loss that reweights reconstruction error toward masked areas.

## Why It Matters
Physics-aware video generation is an important open problem for world models and simulation. The VLM-as-reasoner approach for identifying dynamic regions is a clean modular design that separates spatial reasoning (VLM) from visual synthesis (video model)—the VLM doesn't need video generation knowledge and the video model doesn't need to learn physics from scratch. The training-free variant (DeforM-Free) is particularly appealing as a zero-shot add-on to any existing video generation model. Relevant to priority 2 (video generation) and to understanding how reasoning capabilities can guide generation.
