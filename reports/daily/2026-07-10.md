### 1. OpenCoF: Learning to Reason Through Video Generation
**Score: 87/100** · [arXiv:2607.08763](https://arxiv.org/abs/2607.08763)
**Authors:** Xinyan Chen, Ziyu Guo, Renrui Zhang, Dongzhi Jiang, Hongsheng Li (ByteDance Seed, CUHK MMLab)
**Project:** https://opencof.github.io/

## TL;DR
OpenCoF establishes Chain-of-Frame (CoF) reasoning — using temporally connected video frames as the reasoning medium instead of text tokens — and releases OpenCoF-17K (17,312 videos across 11 task families) plus Wan-CoF, a fine-tuned video model that shows substantial gains over its baseline on four video reasoning benchmarks.

## Problem
Mainstream visual Chain-of-Thought pipelines rely on static visual observations and cannot intrinsically model dynamic transitions or multi-step visual consequences. Video generation models have shown early signs of physical/causal understanding, but lack dedicated training data and designs for Chain-of-Frame (CoF) reasoning — the paradigm in which reasoning unfolds through the temporal evolution of generated frames rather than through text.

## Key Contributions
- **OpenCoF-17K dataset:** 17,312 reasoning videos spanning 11 task families, constructed through four complementary pipelines (instance-based rendering, expert-guided rendering, procedural scene synthesis, and external video repurposing) to provide diverse temporal supervision for CoF reasoning.
- **Wan-CoF model:** A fine-tuned video model built on Wan2.2-I2V-A14B that achieves considerable gains across four video reasoning benchmarks (RULER-Bench, Gen-ViRe, VIPER, and others) by training on broad temporal supervision from OpenCoF-17K.
- **Reasoning token mechanisms:** Empirical exploration of visual reasoning tokens (vt) capturing low-level visual cues and textual reasoning tokens (tt) capturing high-level semantic priors, with attention analysis across model depth, denoising steps, and spatial/temporal dimensions to understand how these tokens contribute to CoF behavior.

## Method
OpenCoF frames video generation as a reasoning chain: each generated frame is both the output and the next step of inference, analogous to a thought in CoT. The dataset is built via four complementary pipelines to cover diverse temporal reasoning patterns across 11 task families. Wan-CoF is fine-tuned on this dataset, then further equipped with visual and textual reasoning tokens that serve as explicit intermediate representations. Attention analysis reveals how these tokens organize reasoning across the denoising trajectory (depth-wise, step-wise, spatial, temporal), providing mechanistic insight into CoF computation.

## Why It Matters
This work opens a new paradigm: instead of reasoning purely through language, AI systems can reason through visual simulation — generating intermediate frames that externalize dynamic consequences, physical transitions, and causal chains. For researchers working at the intersection of video generation and agentic AI, CoF reasoning represents a promising path toward AI that can think in images and simulate the future. The fully open release (dataset + model + code) makes this a concrete starting point for the field.

### 2. Cognitive-structured Multimodal Agent for Multimodal Understanding, Generation, and Editing
**Score: 82/100** · [arXiv:2607.08497](https://arxiv.org/abs/2607.08497)
**Authors:** Feng Wang, Canmiao Fu, Zhipeng Huang, Chen Li, Jing Lyu, Ge Li (Peking University, WeChat Vision, Tencent)
**Project:** https://caseclose.github.io/cma-harness

## TL;DR
CMA is an 8B cognitive agent architecture that externalizes visual memory into an Episodic Visual Memory module, achieving 91.4% retrieval accuracy over 20-turn multimodal sessions and halving per-turn inference time — outperforming 32B baselines by +8.2% on long-horizon visual recall.

## Problem
Unified multimodal models that jointly perform vision understanding and image generation/editing face "visual token explosion" in long-horizon dialogue: repeatedly feeding all historical visual tokens into a shared context window crowds out the reasoning budget, and implicit attention over long histories causes cross-turn visual referencing errors. Strong unified models (e.g., BAGEL) correctly retrieve visual episodes in fewer than 3% of the hardest cases in a 20-turn benchmark.

## Key Contributions
- **Cognitive-structured Multimodal Agent (CMA):** Three modular components — Perceptual Abstraction Engine (structured visual abstraction into compact representations), Cognitive Retrieval Engine (selective cross-turn memory reactivation), and Multimodal Executive Controller (task inference and action planning) — organized around an Episodic Visual Memory (EVM) that stores and retrieves visual episodes across turns.
- **Unified Scenario Engine:** Programmatically generates structured multi-turn multimodal conversations with fine-grained turn-level retrieval annotations, enabling reinforcement learning to optimize both perceptual abstraction and retrieval policies where prior datasets lacked such supervision.
- **CMA-Harness:** Tool-augmented deployment integrating persistent multimodal memory, web access, image generation/editing/composition tools, and OpenAI-compatible serving — showing the same cognitive architecture scales to real-world agentic deployments.

## Method
Rather than feeding raw visual tokens into a growing context, CMA passes each visual input through a Perceptual Abstraction Engine that produces a compact structured representation stored in the EVM. At generation time, the Cognitive Retrieval Engine queries the EVM to selectively reactivate relevant visual episodes. The Multimodal Executive Controller sequences actions (understanding, generation, editing) based on retrieved context. The Unified Scenario Engine constructs RL training data with retrieval annotations, enabling policy optimization for perceptual abstraction and retrieval. An 8B agent trained this way achieves 91.4% retrieval accuracy and 23.1s→12.7s per-turn inference speedup.

## Why It Matters
The agent paradigm — separate memory, retrieval, and execution modules — can decisively outperform larger monolithic parameter scaling for long-horizon multimodal tasks requiring referencing, iterative editing, and generation across many conversation turns. This work demonstrates that structured cognitive architectures are a scalable path to general-purpose AI assistants that need to interleave perception and generation in extended sessions, and the CMA-Harness provides an immediately deployable system.

### 3. OPSD-V: On-Policy Self-Distillation for Post-Training Few-Step Autoregressive Video Generators
**Score: 82/100** · [arXiv:2607.08766](https://arxiv.org/abs/2607.08766)
**Authors:** Hongyu Liu, Chun Wang, Feng Gao, Xuanhua He, Yue Ma, Ziyu Wan, Yong Zhang, Xiaoming Wei, Qifeng Chen (Meituan, HKUST, City University of Hong Kong)
**Project:** https://meigen-ai.github.io/OPSD-V · **Code:** MeiGen-AI/OPSD-V

## TL;DR
OPSD-V is an on-policy self-distillation training paradigm that augments few-step autoregressive video generation with real long-video context as dense corrective teacher supervision, improving motion dynamics and long-horizon stability without changing the inference-time sampler — preferred by users 82.5% of the time over base models.

## Problem
Autoregressive (AR) video diffusion models achieve real-time streaming generation via causal architectures and few-step distillation (e.g., Self-Forcing, LongLive), but suffer from error accumulation and weakened motion dynamics during long rollouts. The root cause is a train-inference mismatch: training on short clips does not expose the model to the compounding KV-cache drift that occurs during long sequential generation.

## Key Contributions
- **On-policy student rollout:** The student follows the exact inference-time AR procedure — generating each chunk conditioned on its own previously generated KV cache — closing the train-inference gap by training on the same distribution the model encounters at test time.
- **AR-Consistent Real-Video Teacher Cache:** The teacher is evaluated at the same denoising states as the student but uses a cache in which older chunks are replaced by real long-video context (while keeping the most recent model-generated chunk), providing a richer and cleaner target distribution without becoming a fully teacher-forced oracle.
- **Dense denoising-level objective:** Supervision is applied at every denoising step (velocity/flow-matching targets), not just at the final generated frame, providing dense corrective signal across the full diffusion trajectory; combined with memory-efficient truncated backpropagation for long sequences.

## Method
OPSD-V trains two parallel branches sharing an initial real-video prefix. The student generates all chunks autoregressively using its own rolling KV cache (exact inference-time behavior). The teacher evaluates at the same denoising states but replaces older cache history with real long-video clips. A dense denoising-level loss aligns student to teacher at every step, using velocity targets. Applied to Self-Forcing and LongLive, OPSD-V improves VBenchLong scores and is preferred in 82.5% of paired user comparisons (excluding ties).

## Why It Matters
Real-time AR video generation (streaming avatars, interactive video synthesis, live content creation) requires models that maintain coherent, dynamic motion over long horizons — a persistent bottleneck since standard distillation targets short clips. OPSD-V's approach is model-agnostic (applied here to two different AR video architectures), does not change inference, and directly addresses the core training distribution mismatch, making it immediately applicable to any few-step AR video pipeline.
