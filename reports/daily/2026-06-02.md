### 1. Reasmory: 3D Reconstruction as Explicit Memory for VLMs Spatial Reasoning
**Score: 93/100** · [arXiv:2606.00963](https://arxiv.org/abs/2606.00963)

**Authors:** Jixuan He, **Xueting Li**, Chieh Hubert Lin, **Ming-Hsuan Yang**

*Notable: close collaborators Xueting Li (NVIDIA) and Ming-Hsuan Yang (UC Merced) are authors.*

## TL;DR
Reasmory builds explicit 3D point-cloud memory from multi-view images or video and constrains VLM interaction with that memory via a validated domain-specific language (DSL), achieving 6–18% gains over GPT-5-mini and Gemini-3-flash on spatial reasoning benchmarks.

## Problem
VLMs are unreliable at precise spatial reasoning tasks (viewpoint reasoning, directional comparison, distance estimation) because relevant spatial cues are sparse and scattered across redundant observations. Simply exposing 3D reconstruction tools to VLMs as free-form calls is brittle: VLMs invoke tools incorrectly, skip required spatial transformations, or misuse intermediate results.

## Key Contributions
1. **Explicit 3D spatial memory**: builds point clouds from multi-view images/video augmented with semantically grounded 3D object instances, converting sparse frame evidence into a geometrically consistent spatial representation.
2. **Constrained DSL for memory interaction**: introduces a lightweight Domain-Specific Language that restricts how VLMs query objects, transform viewpoints, and render observations — programs are parsed and validated before execution, preventing the errors common with unconstrained tool use.
3. **Consistent benchmark gains**: 6–18% improvement over strong baselines (GPT-5-mini, Gemini-3-flash) on multi-view image and video spatial reasoning benchmarks, with a controlled study showing that even manual frame selection provides only marginal gains (+1%) versus the 7.5% gain from explicit structured memory.

## Method
Given multi-view images or monocular video, Reasmory runs a reconstruction model to produce a point cloud, augments it with semantic 3D object bounding volumes, and then generates DSL programs that query this memory in structured, validated steps. The DSL exposes operations for object querying, viewpoint transformation, and rendering. Generated programs are syntactically validated and type-checked before execution. The VLM writes programs (not free-form text) to interact with the 3D memory, making each reasoning step inspectable and verifiable.

## Why It Matters
Demonstrates that structured, validated access to explicit 3D memory dramatically outperforms unconstrained tool use for spatial reasoning — a key capability for embodied AI, VLA models, and navigation. The collaborator connection (Xueting Li, Ming-Hsuan Yang) makes this directly relevant to the lab's ongoing work.

### 2. OpenWebRL: Demystifying Online Multi-turn Reinforcement Learning for Visual Web Agents
**Score: 83/100** · [arXiv:2606.02031](https://arxiv.org/abs/2606.02031)

**Authors:** Rui Yang, Qianhui Wu, Yuxi Chen, Hao Bai, Wenlin Yao, Hao Cheng, Baolin Peng, Huan Zhang, Tong Zhang, Jianfeng Gao

*Project page: https://openwebrl.github.io*

## TL;DR
OpenWebRL is the first fully open-source framework for training visual web agents with online multi-turn RL on real websites; OpenWebRL-4B achieves 67.0% on Online-Mind2Web and 64.0% on DeepShop using only 0.4K initialization trajectories, competitive with proprietary systems like OpenAI CUA.

## Problem
Strong visual web agents remain largely proprietary; open agents still depend on expensive curated offline trajectories (e.g., 278K trajectories for MolmoWeb), creating a scalability bottleneck. Online RL for visual web agents on live websites is largely unexplored due to challenges in dynamic web environments, slow browser interaction, and lack of reliable automated reward signals.

## Key Contributions
1. **Full open-source RL pipeline**: covers scalable live-browser infrastructure with sandboxed execution, timeout/recovery, supervised initialization, multimodal context management, trajectory-level success judging (OpenWebRL-Judge-8B), and efficient multi-turn policy optimization.
2. **Multimodal Multi-turn GRPO (MM-GRPO)**: extends GRPO to the multi-turn visual web setting, enabling efficient online policy optimization over real website interactions with outcome-based trajectory-level rewards.
3. **New SOTA on live-web benchmarks**: OpenWebRL-4B achieves 67.0% on Online-Mind2Web and 64.0% on DeepShop, outperforming all prior open agents of similar or larger scale and remaining competitive with proprietary systems using ×650 less training data.

## Method
OpenWebRL has four components: (1) a robust browser infrastructure with sandboxed Chromium, timeout/recovery, and failure attribution; (2) supervised initialization on 0.4K curated trajectories to seed the policy; (3) OpenWebRL-Judge-8B, a trajectory-level success judge trained to assess open-ended task completion on real websites; (4) MM-GRPO for online multi-turn RL — the agent interacts with live websites, receives outcome-based rewards, and iteratively improves through group relative policy optimization over multi-turn trajectories. Training data, models, and code will be released.

## Why It Matters
Provides a reproducible, cost-efficient open path to training capable visual web agents — a key capability in agentic AI. The 10× data efficiency improvement over supervised approaches and competitive performance with proprietary systems shows that online RL is the right training paradigm for web agents, not dataset curation.

### 3. MORPHOS: Autoregressive 4D Generation with Temporal Structured Latents
**Score: 83/100** · [arXiv:2606.02491](https://arxiv.org/abs/2606.02491)

**Authors:** Minkyung Kwon, Jinhyeok Choi, Youngjin Shin, Jaeyeong Kim, JongMin Lee, Seungryong Kim

*Project page: https://cvlab-kaist.github.io/MORPHOS*

## TL;DR
MORPHOS introduces Temporal Structured Latents (T-SLat) and autoregressive causal attention to generate dynamic 3D assets — simultaneously in mesh, 3D Gaussian, and NeRF formats — from video, achieving SOTA appearance and long-horizon temporal consistency with evolving topologies.

## Problem
Existing 4D generation methods either support a single 3D representation (mesh or Gaussian splatting), fail to model topological changes (birth/merging of objects), or lose temporal consistency over long video sequences. No prior method handles all three major 3D representations in one unified framework.

## Key Contributions
1. **Temporal Structured Latents (T-SLat)**: extends 3D structured latents to the temporal dimension, jointly encoding geometry and appearance across time to handle complex structural transformations including topology changes.
2. **Autoregressive causal generation**: two flow models (sparse voxel generator + T-SLat generator) use causal attention conditioning each frame on all preceding history, enabling long-horizon 4D generation with KV-caching for efficient inference.
3. **Temporal-structural augmentation**: perturbs the conditioning history during training to mitigate error accumulation in autoregressive generation; achieves SOTA appearance on multiple benchmarks across meshes, 3D Gaussians, and radiance fields simultaneously.

## Method
MORPHOS uses two cascaded autoregressive flow models. The first generates a sparse voxel structure per frame; the second generates T-SLat (temporal structured latents) conditioned on that structure. Both models use causal attention over the temporal sequence, conditioning each new frame on all previous T-SLat frames. At inference, KV-caching significantly reduces redundant computation. Temporal-structural augmentation randomly corrupts the conditioning history during training to improve robustness to error accumulation. A single model decodes T-SLat into meshes, 3D Gaussians, or NeRF as needed.

## Why It Matters
First unified 4D generation framework handling all three dominant 3D representations. Directly applicable to 4D digital content creation (game assets, animation, VFX) and enables downstream 4D editing. The autoregressive causal design allows streaming generation of arbitrarily long dynamic 3D sequences.

### 4. Towards 3D-Aware Video Diffusion Models: Render-Free Human Motion Control with Mesh Tokenization
**Score: 82/100** · [arXiv:2606.02000](https://arxiv.org/abs/2606.02000)

**Authors:** Jingyun Liang, Min Wei, Shikai Li, Yizeng Han, Hangjie Yuan, Lei Sun, Weihua Chen, Fan Wang

*Project page: https://jingyunliang.github.io/MeshToken*

## TL;DR
MeshToken proposes render-free human motion control for video diffusion by conditioning directly on VQ-compressed 3D SMPL mesh tokens instead of rendered 2D guidance, enabling 3D-aware generation that reduces artifacts and supports editing across viewpoints and pose variations.

## Problem
Most human motion control approaches project 3D motion into rendered 2D guidance signals (pose maps, skeleton videos) that are view-dependent and discard 3D geometric information. This reduces the task to video-to-video translation, and during editing introduces artifacts such as floating feet, body penetration, and trajectory-pose mismatches under different camera viewpoints.

## Key Contributions
1. **Render-free 3D motion conditioning**: directly compresses 3D SMPL mesh sequences (trajectory + body pose) via VQ-VAE into compact latent tokens, bypassing view-dependent rendering entirely.
2. **Unified token-based DiT pipeline**: processes video tokens jointly with 3D mesh tokens through cross-attention in a DiT-based architecture, requiring the model to reason about 3D structure rather than mimic 2D guidance.
3. **Probes 3D awareness**: provides an experimental framework showing that video diffusion models equipped with mesh tokenization reduce view-dependent artifacts and better handle editing under trajectory-pose mismatches.

## Method
Human motion is represented as SMPL-based trajectory + body pose mesh sequences. A VQ-VAE compresses each mesh frame into compact latent tokens. Trajectory embeddings are combined with mesh tokens to form unified motion tokens, which are injected into a DiT-based video generation backbone via per-frame cross-attention. No rendering pipeline is required: the model must infer how 3D geometry projects into 2D appearance under the given camera viewpoint, directly probing 3D awareness.

## Why It Matters
Addresses a fundamental limitation in controllable human video generation — view-dependent 2D guidance — with a principled 3D alternative. Relevant to generating realistic human video for digital avatars, telepresence, and motion editing workflows.

### 5. Spatial-Temporal Decoupled Reference Conditioning for Identity-Preserving Text-to-Video Generation
**Score: 82/100** · [arXiv:2606.02441](https://arxiv.org/abs/2606.02441)

**Authors:** Yuheng Chen, Teng Hu, Yuji Wang, Qingdong He, Lizhuang Ma, Jiangning Zhang

*Code: https://github.com/AliothChen/ST-DRC*

## TL;DR
ST-DRC decouples spatial and temporal reference conditioning in identity-preserving text-to-video generation: reference tokens are temporally adjacent to video tokens (for identity attention) but spatially shifted (to prevent pixel-level copying), achieving strong face identity preservation while maintaining text adherence and temporal consistency.

## Problem
Identity-preserving video generation (IPVG) must balance high-level semantic control (following text prompts for actions, scenes, and dynamics) with low-level facial identity fidelity (preserving exact facial details from a reference image). Adapter-based semantic injection compresses identity details, while naive latent injection creates copy-paste shortcuts that fail to generalize across pose/lighting.

## Key Contributions
1. **Latent in-context reference injection**: encodes the reference image with the video VAE and concatenates it to noisy video latents, giving low-level identity detail access without additional adapter modules.
2. **TASS-RoPE (Temporal-Adjacent Spatial-Shifted RoPE)**: places reference tokens as temporally adjacent (enabling identity attention) but spatially shifted (suppressing pixel-level copy-paste), allowing fine-grained identity information to flow through spatio-temporal attention while preserving compositional generalization.
3. **Three-stream classifier-free guidance**: independently controls text adherence and reference fidelity at inference time, enabling flexible trade-off between prompt alignment and identity preservation.

## Method
The reference image is encoded by the video VAE and concatenated with noisy video latents. TASS-RoPE modifies rotary positional embeddings so reference tokens appear temporally near the video sequence but are offset in the spatial dimension. Appearance-invariant augmentation (color jitter, pose variation) combined with face-guided identity objectives (ArcFace) prevent shortcut learning. Three-stream CFG at inference allows independent control: text guidance, reference guidance, and their combination. Built on LTX-2.3, ST-DRC ranks top in the facial IPVG challenge at ACM MM 2026.

## Why It Matters
Directly advances human-centric video generation — a top priority area — by providing a lightweight yet effective solution to the identity-preservation challenge. The spatial-temporal decoupling insight elegantly resolves the tension between identity fidelity and semantic control.

### 6. Thinking in Blender: Staged Executable Inverse Graphics with Vision-Language Models
**Score: 81/100** · [arXiv:2606.02580](https://arxiv.org/abs/2606.02580)

**Authors:** Guangzhao He, Rundong Luo, Wei-Chiu Ma, Hadar Averbuch-Elor

## TL;DR
SEIG (Staged Executable Inverse Graphics) reconstructs editable 3D Blender scenes from single images by decomposing reconstruction into sequential stages (geometry → materials → composition → lighting), each with a generator-verifier loop, driven entirely by a pretrained VLM writing executable Blender code — no specialized 3D models or differentiable rendering required.

## Problem
Inverse graphics — reconstructing images as editable 3D scenes — is highly underconstrained. VLMs struggle to simultaneously recover all scene factors (geometry, materials, composition, lighting). Existing approaches require specialized 2D or 3D foundation models, differentiable rendering pipelines, or multi-view supervision.

## Key Contributions
1. **Staged reconstruction decomposition**: decomposes the problem into sequential stages mirroring the professional 3D artist workflow, substantially improving reconstruction fidelity over monolithic approaches by reducing per-stage complexity.
2. **Generator-verifier loop**: each stage renders the current Blender scene and feeds it back to the VLM for visual verification, enabling targeted corrections before proceeding to the next stage.
3. **Rich downstream applications**: the output is a fully editable Blender program enabling novel-view synthesis, object editing, material editing, and scene relighting as downstream applications — without any additional training.

## Method
From a single input image, SEIG initializes a coarse Blender scene scaffold (simple geometric primitives, approximate layout). It then progresses through sequential stages: geometry refinement, material assignment, compositional arrangement, and lighting setup. At each stage, a pretrained VLM generates or refines Blender Python code that is executed in a Blender renderer; the rendered output is fed back for VLM verification and critique. This staged generator-verifier loop runs within each stage before advancing. No differentiable rendering or specialized 3D foundation models are used.

## Why It Matters
Shows that agentic VLMs can perform complex 3D reconstruction through structured code generation and staged verification — enabling practical inverse graphics from single images with rich downstream editing capabilities. The finding that task decomposition matters more than toolkit richness is broadly applicable to agentic AI system design.

### 7. Geometry-Aware Implicit Memory for Video World Models
**Score: 80/100** · [arXiv:2606.02436](https://arxiv.org/abs/2606.02436)

**Authors:** Zhengxuan Wei, Xu Guo, Xinghui Li, Xunzhi Xiang, Min Wei, Yiran Zhu, Qiulin Wang, Xintao Wang, Pengfei Wan, Xiangwang Hou, Qi Fan

*Project page: https://gim-world.github.io/*

## TL;DR
GIM-World compresses video history into fixed-size implicit memory tokens supervised by a frozen 3D geometry foundation model during training, enabling long-horizon geometrically consistent rollouts in video world models without explicit frame retrieval or online reconstruction at inference.

## Problem
Long-horizon video world models need memory of past observations, but explicit memory (frame retrieval or online 3D reconstruction) is heuristic and error-prone. Existing implicit memory designs lack geometric training signals and learn to compress appearance redundancy rather than cross-view 3D scene structure.

## Key Contributions
1. **Geometry-aware implicit memory**: a lightweight transformer encoder compresses variable-length history into fixed-size memory tokens, with a camera-queryable geometry head distilling 3D scene structure from a frozen foundation model during training — the geometry teacher is discarded at inference.
2. **Information-guided pruning**: keeps encoding cost bounded as history grows by selectively retaining the most informative frames for memory encoding.
3. **Outperforms both baselines on MIND**: beats both explicit-memory (frame retrieval, online 3D reconstruction) and implicit-memory baselines on long-horizon geometric and visual consistency metrics, while adding only a lightweight memory module at inference.

## Method
A transformer-based memory encoder takes variable-length historical frames and produces fixed-size memory tokens. During training, a frozen 3D geometry foundation model (geometry teacher) provides depth and camera-viewpoint features as auxiliary supervision signals for the memory — constraining the memory to encode cross-view scene structure rather than just appearance. At inference, only the lightweight memory encoder is used with no geometry teacher. Camera queries allow retrieving geometry-consistent predictions from specific viewpoints. Information-guided pruning selects which historical frames to encode to keep cost bounded.

## Why It Matters
Enables persistent, 3D-consistent video world models without the overhead of online reconstruction — critical for embodied AI simulators, interactive game engines, and long-horizon robot planning. The key insight that geometry should be a property of the memory (not just an input signal to the generator) is clean and principled.

### 8. VESTA: Visual Exploration with Statistical Tool Agents
**Score: 80/100** · [arXiv:2606.00384](https://arxiv.org/abs/2606.00384)

**Authors:** William Rudman, Abhishek Divekar, Kanishk Jain, Sebastian Joseph, Stella S. R. Offner, Matthew Lease, Kyle Mahowald, Greg Durrett, Junyi Jessy Li

*Code: https://github.com/wrudman/VESTA*

## TL;DR
VESTA equips VLMs with a dynamically growing toolkit of visual diagnostic tools to iteratively fit statistical models to data — including real-world astronomy tasks (gravitational-wave chirp signals, initial mass functions) — substantially outperforming prior agentic pipelines through dynamic tool creation that accumulates in context and is reused.

## Problem
Statistical model fitting is a central yet under-automated step in scientific workflows. Agent-based systems relying only on iterative text critique struggle with challenging or domain-specific tasks. Scientific domains require expertise that static pre-built tool sets cannot cover.

## Key Contributions
1. **Dynamic visual tool creation**: VLMs can select or create diagnostic tools (data transformations, hypothesis-driven visualizations, statistical tests) that accumulate across refinement rounds and are reused — unlike prior systems that rely on iterative critique alone.
2. **DAWN benchmark**: covers distribution fitting and time series modeling with three difficulty tiers, culminating in real-world astronomy tasks: initial mass functions and gravitational-wave chirp signals.
3. **Dynamic beats static**: dynamically generated tools outperform expert-written static tool sets, especially on complex and domain-specific tasks; generated tools cover more diagnostic categories per function and strongly prefer visual outputs the VLM can reason over.

## Method
VESTA wraps a VLM in a propose-evaluate-refine loop over PyMC Bayesian probabilistic models. At each iteration, the agent selects or creates visual diagnostic tools (writing Python code), executes them to produce diagnostic visualizations, inspects these visualizations as multimodal input, and critiques model fit quality. Successfully created tools accumulate in the agent's context and can be reused across iterations. The framework operates over three toolkit configurations: no tools, static expert tools, and dynamic model-written tools.

## Why It Matters
Demonstrates automated scientific discovery at the level of statistical model fitting — one of the most expertise-intensive steps in research pipelines. The dynamic tool creation approach generalizes to novel scientific domains, directly relevant to the lab's interest in AI scientist systems and automated research agents.
