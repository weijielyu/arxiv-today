## Top Picks (Score ≥ 85)

### 1. GenClaw: Code-Driven Agentic Image Generation

**Score: 85/100** · [arXiv:2605.30248](https://arxiv.org/abs/2605.30248)

**Authors:** Junyan Ye, Jun He, Zilong Huang, Dongzhi Jiang, Xuan Yang

## TL;DR
GenClaw is a code-driven agentic image generation framework that uses LLMs to write executable code (SVG, HTML, Three.js) as a "digital brush" for precise spatial layout, then employs image generation models for photorealistic texture and material synthesis — replacing the prompt-rewriting loop with a human-like conceptualize → sketch → color pipeline.

## Problem
Existing image generation agents remain bottlenecked by end-to-end black-box text-to-image models: agents can only refine outputs by rewriting prompts, with no mechanism to directly control spatial layout, object count, text rendering, or layer occlusion. Natural language is inherently ambiguous for expressing absolute coordinates, object counts, and typographic layouts, limiting agent control over visual-spatial structure. Current agents are reduced to "advanced prompt optimizers" rather than genuine creative agents.

## Key Contributions
1. **Code-as-Canvas Paradigm**: Uses executable code (SVG, HTML, Three.js) as a structured intermediate representation between LLM reasoning and pixel synthesis. Code carries explicit geometry, coordinate references, layer ordering (z-order), and logical structure that natural language cannot reliably convey, giving agents direct control over the visual canvas.
2. **Three-Stage Agentic Pipeline**: Conceptualize (search + reasoning for knowledge/context) → Sketch (code execution for structural layout) → Color (image generation model adds photorealistic textures). Each stage has clear responsibility and failure mode, enabling fully traceable debugging across the entire creative process.
3. **Multi-Domain Advantages**: Demonstrated improvements in compositional control (complex multi-object scenes via structured code), text rendering (code-based typography eliminates hallucinated characters), physics-assisted simulation (Three.js for 3D scene references), and layered image editing (JSONL layer decomposition for precise per-region manipulation).

## Method
The agent first invokes search and reasoning tools to gather entity knowledge and context (Conceptualize). It then writes executable code — SVG for 2D layouts, HTML/CSS for typography, Three.js for 3D and physics — to construct a structured sketch canvas (Sketch). Finally, an underlying generative model (e.g., GPT-Image, Qwen-Image) takes the rendered code sketch as visual conditioning and adds photorealistic textures, materials, and fine detail (Color). The code sketch serves as a controllable visual-condition input, reducing the image model's burden of interpreting complex linguistic spatial instructions. Layered image editing uses a JSONL layer decomposition format to precisely isolate and manipulate target regions without corrupting unedited pixels.

## Results
Evaluated on compositional generation tasks (complex multi-object scenes), typographic text generation, physical simulation tasks, image editing benchmark (ImgEdit), and knowledge-grounded generation (Mind-Bench). GenClaw improves stability in object counting and spatial layout control versus pure prompt-based approaches, near-eliminates spelling errors in text rendering, and achieves substantially reduced unintended pixel corruption in layered editing compared to end-to-end black-box baselines. As a technical report presenting an early-stage system, results are framed as qualitative demonstrations and targeted comparisons against GPT-Image and similar models.

## Why It Matters
Code agents (Claude Code, Codex, etc.) are emerging as powerful general-purpose execution environments; GenClaw is the first systematic attempt to leverage code-as-intermediate-representation specifically for image generation, creating a natural bridge between LLM code generation capabilities and visual synthesis. The decoupled "conceptualize → sketch → color" workflow mirrors human artistic creation, enabling transparent and debuggable visual generation pipelines — a critical step toward interpretable, controllable image generation agents that can be steered programmatically rather than stochastically. For researchers working at the intersection of agentic AI and generative vision, this establishes a new paradigm with direct implications for how autonomous agents will produce and edit visual content.
