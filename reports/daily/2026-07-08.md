### [2607.05465] CanvasAgent: Enabling Complex Image Creation and Editing via Visual Tool Orchestration
**Score: 84/100** · [arXiv:2607.05465](https://arxiv.org/abs/2607.05465)
**Authors:** Hairui Zhu, Yiying Yang, Tengjin Weng, Ziyu Lu, Xiao Yao, Xiaoyang Ye, Lin Ma, Wenhao Jiang
**Code:** [GitHub](https://github.com/GML-FMGroup/CanvasAgent) · [HuggingFace Dataset](https://huggingface.co/datasets/GML-FMGroup/CanvasCraftSFT)

## TL;DR
CanvasAgent is the first tool-augmented multimodal agent purpose-built for complex, multi-step image creation and editing — orchestrating heterogeneous visual tools (generation, segmentation, editing, OCR, compositing, enhancement) through multi-turn stateful interaction, trained on a new 140K-trajectory dataset (CanvasCraft) via SFT and GRPO reinforcement learning with a hybrid outcome-and-process reward.

## Problem
Complex image creation requests require coordinating many tools in sequence: generate a scene, localize an object, segment it, replace that region, add text, crop, and enhance resolution. These workflows are long-horizon (later operations depend on earlier outputs), visually grounded (the agent must inspect intermediate results), and stateful (multiple image assets coexist). Existing multimodal tool-use agents are optimized for perception, search, or single-step editing — none provide large-scale supervision for executable, multi-asset image-creation trajectories.

## Key Contributions
1. **CanvasAgent** — the first tool-augmented MLLM that actively orchestrates heterogeneous vision tools (generation, editing, extraction, compositing, transformation, enhancement) through multi-turn visual creation workflows, maintaining explicit image-asset references and a visual-first inspection protocol.
2. **CanvasCraft dataset** — 140K fully annotated SFT execution trajectories and 10K RL task specifications covering diverse tool combinations, multi-turn visual workflows, and intermediate asset states.
3. **Two-stage training** — SFT on CanvasCraft-SFT to bootstrap valid tool invocations and cross-tool dependencies, then GRPO reinforcement learning on CanvasCraft-RL with a hybrid reward combining alignment score (output vs. instruction), aesthetic score, trajectory validity, rule-based executability, and efficiency penalty for redundant steps.

## Method
CanvasAgent follows a visual-first protocol: after each tool call it inspects the intermediate image output rather than assuming success, tracking multi-asset visual state across the canvas. At training, Stage 1 (SFT) teaches the agent which tools to call and in what order by imitating annotated trajectories. Stage 2 (GRPO) allows exploration of tool ordering, parameterization, recovery from failures, and stopping strategies guided by the hybrid reward — rewarding both final output quality and process correctness. The hybrid reward is the sum of an alignment score (VLM judge comparing result to instruction), an aesthetic score, a trajectory score (reasoning-action coherence), a rule-based reward (valid tool call formatting), and a negative efficiency penalty for superfluous steps.

## Why It Matters
This paper sits squarely at the intersection of the two highest-priority research areas: agentic AI systems (priority #1) and image generation (priority #3). It represents a concrete, fully trained agentic system for visual creation — going beyond passive perception agents to actively constructing complex outputs by coordinating specialized models. The CanvasCraft dataset and GRPO training recipe are immediately reusable for agentic visual research.

### [2607.05511] Light-Omni: Reflex over Reasoning in Agentic Video Understanding with Long-Term Memory
**Score: 81/100** · [arXiv:2607.05511](https://arxiv.org/abs/2607.05511)
**Authors:** Chang Nie, Jiaju Wei, Junlan Feng, Chaoyou Fu, Caifeng Shan
**Project page:** https://clare-nie.github.io/Light-Omni

## TL;DR
Light-Omni replaces the costly "detective-style" iterative reasoning loops of video agents with reflexive single-pass responses by maintaining dual contextual states — a compact global multimodal script and a parametric latent state — achieving 2.4% higher accuracy, 12.1× speedup, and 2.6× GPU memory efficiency over M3-Agent on long-video benchmarks.

## Problem
Memory-augmented video agents (which track long-horizon video streams via external memory) currently rely on heavy iterative workflows: query rewriting, evidence search, chain-of-thought aggregation. This is slow, expensive, and redundant. The root cause is the lack of a global context — retrieval becomes myopic, hunting for local similarity while missing the broader narrative structure. The semantic gap between user queries and stored memory representations forces agents to compensate with costly multi-step reasoning.

## Key Contributions
1. **Light-Omni** — a multimodal agent framework that eliminates iterative reasoning by constructing two complementary contextual states that together provide both global video context and semantically aligned retrieval in a single forward pass.
2. **Global State** — a finite-sized multimodal script (non-parametric) maintained asynchronously via sleep-time hierarchical merging with resolution decay: recent visual/auditory/interactive events are preserved in detail while distant past events are summarized, maintaining global temporal coherence without unbounded context growth.
3. **Latent State** — a parametric representation generated from the global context that simultaneously drives task-specific action heads (speech, search, etc.) and produces retrieval embeddings semantically aligned to the query, eliminating the search-rewrite-retrieve loop and enabling near-constant latency regardless of video length.

## Method
Light-Omni builds a three-tier multimodal memory (identity profiles, semantic store, episodic store). At runtime, a background sleep-time consolidation process continuously updates the global state via hierarchical merging — recent events at full resolution, older events progressively summarized. At query time, a single forward pass through the model conditions on the global state to simultaneously generate the latent state (driving action control heads) and retrieval embeddings (for evidence aggregation). These coupled representations enable reflexive response — no iterative search-rewrite-retrieve cycle. Light-Omni outperforms M3-Agent by 2.4% avg accuracy while running 12.1× faster and using 2.6× less GPU memory; it also plugs in as a memory module to boost other MLLMs.

## Why It Matters
Light-Omni combines the two top-priority research areas — agentic AI (#1) and video (#2) — and demonstrates that lightweight reflex-style architecture can match or exceed heavy reasoning-based agents for long-horizon video understanding. The dual-state design (global non-parametric context + parametric latent state) is a general pattern applicable to any agentic system operating over continuous multimodal streams, with direct implications for real-time AI agents processing video.
