### 1. Meshy T2: Fast Native Mesh Generation with Flow Matching

**Score: 88/100** · [arXiv:2607.28675](https://arxiv.org/abs/2607.28675) · [Project Page](https://github.com/meshy-dev/meshy-t2)

**Authors:** Jiale Xu, Rendong Liang, Yuhao Long, Siyuan Shen, Zangyueyang Xian, Zeyi Xu, Yuanming Hu

## TL;DR
Meshy T2 is a flow-matching framework for image-to-mesh generation that produces artist-quality polygonal meshes with controllable face budgets in ~6 seconds (over 10× faster than autoregressive baselines), using a two-stage coarse-to-fine pipeline: an image-conditioned voxel flow sketches a coarse occupancy scaffold, and a mesh flow populates it with per-vertex latent tokens via a nearly lossless vertex-set VAE.

## Problem
Generating production-ready polygonal meshes automatically remains unsolved at scale: implicit field methods (NeRF, voxels + Marching Cubes) yield hundreds of thousands of near-uniform triangles requiring expensive retopology, while direct autoregressive sequence methods model artist topology but are slow (sequential inference), error-prone (mistakes compound over long token sequences), and struggle with multi-part assets.

## Key Contributions
- **Vertex-set mesh VAE** that encodes/decodes meshes without vertex quantization or welding — vertex positions stay continuous, coincident vertices are never merged, and vertex coordinates, edge connectivity, and face winding order are recovered jointly in one decoder pass, faithfully preserving artist topology and part structure.
- **Two-stage flow-matching pipeline**: image-conditioned voxel flow → image-and-voxel-conditioned mesh flow, using optimal-transport positional encodings to assign canonical positions to unordered vertex tokens, enabling fully parallel inference.
- **Interactive face-count control** via a requested vertex budget at inference time, without post-hoc simplification; **native multi-part support** where components emerge directly from the predicted connectivity graph.

## Method
The mesh VAE maps each ground-truth vertex to one continuous latent token by combining surface-sampled voxel context with vertex queries and graph attention over mesh edges. The decoder recovers vertex coordinates, undirected edges, and local halfedge permutations from the latent set in a single pass, assembling the final mesh from predicted edges and halfedge successor mappings. For generation: Stage I trains an image-conditioned voxel flow model to produce a 64³ occupancy scaffold; Stage II trains a mesh flow model conditioned on the image, the scaffold, and a vertex-count signal, generating all per-vertex latent tokens in parallel via rectified flow. Optimal transport assigns positional encodings to unordered vertex slots. End-to-end generation completes in a median of 6 seconds.

## Why It Matters
This is state-of-the-art on both mesh retopology and image-to-mesh generation tasks, and the only method combining interactive speed, artist-quality topology, face-budget control, and native multi-part decomposition in one framework. Code and weights are released at https://github.com/meshy-dev/meshy-t2, making this directly deployable for 3D content creation pipelines in film, gaming, and interactive 3D (priority 4).

### 2. MoRoute: Dynamic Routing for In-Context Multimodal Video Generation

**Score: 82/100** · [arXiv:2607.29545](https://arxiv.org/abs/2607.29545) · [Project Page](https://orange-3dv-team.github.io/MoRoute/)

**Authors:** Chong Gao, Jie Ma, Zhan Peng, Chongxiao Wang, Haoxue Wu, Jun Liang, Guanbin Li, Jing Li

## TL;DR
MoRoute unifies text-, image-, and video-conditioned video generation in a single model by treating a frozen VLM (Qwen3.5-9B) and a pretrained video DiT (Wan2.1-14B) as heterogeneous experts connected via block-wise dynamic layer routing — letting each DiT block adaptively select which VLM layer is most relevant for its generation stage — and achieves consistent SOTA across three multimodal video generation benchmarks.

## Problem
Practical video generation increasingly demands multimodal control (reference images specifying identity, source videos grounding edits, keyframes anchoring temporal structure), but most video DiTs use text-only encoders. Existing VLM-to-DiT bridges either inject only the final VLM layer (wasting hierarchical information) or require co-training architecturally matched models from scratch (precluding reuse of separately pretrained backbones). One-model-per-task training further prevents tasks from sharing complementary data and generative priors.

## Key Contributions
- **Block-wise dynamic VLM layer routing**: a lightweight per-block router computes dot-product logits between learnable block queries and per-layer VLM key encodings, selecting the most relevant VLM layer per DiT block via straight-through argmax — learning input-dependent, depth-adaptive VLM-to-DiT correspondence without architectural constraints.
- **Unified in-context conditioning**: reference images and source videos concatenated directly into the DiT token sequence via slotted temporal RoPE and sparse attention, preserving fine-grained visual details without auxiliary adapters.
- **Omni-task training**: one model handles TI2V, TV2V, and TIV2V tasks simultaneously, allowing diverse tasks to share complementary data and generative priors (e.g., character-replacement trained with synthetic triples is implicitly improved by real reference-to-video data sharing the same model).

## Method
The frozen Qwen3.5-9B VLM encodes all input conditions into 32 layers of hierarchical representations (D_h=4096). The Wan2.1-T2V-14B DiT (40 blocks, D_d=5120) is equipped with a lightweight per-block router: each router mean-pools per-layer VLM representations, computes a learnable layer key encoding, and selects one VLM layer per DiT block via straight-through argmax with a Gaussian position prior and diversity/confidence/monotonicity regularization objectives. A dedicated per-block projection MLP then maps the selected hidden state into DiT cross-attention context. In-context conditioning uses slotted temporal RoPE with non-overlapping slot assignment and sparse attention for computational efficiency. Progressive multi-task training uses real video data and synthetic paired data across tasks.

## Why It Matters
Demonstrates that separately pretrained, architecturally heterogeneous VLM and video DiT backbones can be unified with minimal added parameters by learning the layer correspondence dynamically — improving average scores by 0.15, 0.18, and 0.34 (on a 1–5 scale) over the best competing method on IntelligentVBench, OpenVE-Bench, and RefVIE-Bench respectively. The multi-task training paradigm is directly relevant to building generalist video generation models (priority 2).

### 3. FlexComposer: Unified Video Compositing from Images to Dynamic Footage with Flexible Trajectory Control

**Score: 80/100** · [arXiv:2607.29627](https://arxiv.org/abs/2607.29627) · [Project Page](https://arxiv.org/abs/2607.29627)

**Authors:** Songchun Zhang, Sitong Guo, Xianghao Kong, Pengwei Liu, Yuwei Guo, Lvmin Zhang, Anyi Rao

## TL;DR
FlexComposer unifies the insertion of both static images and pre-animated video clips into target video sequences via trajectory-guided conditional generation, resolving the control-fidelity trade-off through a Unified Canonical Foreground Representation and a parameter-free Spatial-Aware Latent Injection mechanism that exploits VAE translation equivariance for precise placement without auxiliary adapters.

## Problem
Existing generative video compositing methods face a fundamental control-fidelity trade-off: zero-shot animators hallucinate motion from static reference images (failing to preserve dynamics of pre-animated assets), while semantic-level editors lack fine-grained spatial control for precise trajectory-guided placement. No unified method handles both static images and dynamic video clips as foreground inputs while preserving intrinsic fidelity and supporting exact trajectory control.

## Key Contributions
- **Unified Canonical Foreground Representation**: decouples an object's intrinsic motion from its global displacement by stabilizing dynamic video inputs into centered canonical latent sequences at the pixel level, enabling uniform treatment of heterogeneous inputs (static images and dynamic videos) by the same pipeline.
- **Spatial-Aware Latent Injection**: a parameter-free mechanism that exploits VAE latent translation equivariance to transport canonical features to user-defined trajectory positions frame by frame, without auxiliary ControlNet-style adapters.
- **Hybrid Dataset + Synthetic-to-Real Curriculum**: three-phase training — procedural simulation for geometric grounding, real cinematic footage for realism, generative data for semantic diversity — enabling implicit learning of physically plausible illumination and shadow harmonization without explicit 3D reconstruction.

## Method
Given a foreground asset (static image or dynamic video clip) and a user-defined 2D trajectory, FlexComposer first stabilizes the foreground by removing global displacement to produce a canonical representation preserving only intrinsic motion. The Spatial-Aware Latent Injection step exploits the translation equivariance property of VAE latent spaces to directly shift canonical latent features to the target position along the trajectory for each frame — a parameter-free operation that preserves temporal synchronization. The composed condition is passed to a pretrained video DiT for final generation. Three-phase curriculum training progressively builds geometric understanding, real-world appearance, and semantic generalization.

## Why It Matters
Unifying static-image and dynamic-footage compositing in a single framework is essential for professional video production and personalized content creation. The parameter-free injection avoids the quality degradation and added optimization cost of auxiliary adapters. Outperforms SOTA methods in visual quality, temporal consistency, and trajectory adherence across static and dynamic foreground compositing benchmarks — directly relevant to video generation and editing (priority 2).
