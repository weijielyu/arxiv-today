### Score: 86/100 · [2607.16355](https://arxiv.org/abs/2607.16355) · PhysAgent: Reflective Agentic Physics Control for Physically Plausible Video Generation

**Authors:** Qirui Li, Jinkun Hao, Yibo Li, Ran Yi, Paul L. Rosin, Yu-Kun Lai

## TL;DR
PhysAgent is a closed-loop agentic framework that treats physics simulation specifications as executable hypotheses, iteratively generating, verifying, and repairing physical control programs to produce physically plausible videos from a single image and a text prompt—replacing brittle one-shot VLM prediction with feedback-driven refinement.

## Problem
Physics-grounded video generation relies on a VLM to predict a full simulator specification (scene state + motion parameters) in a single pass. Because many tightly coupled parameters must be simultaneously correct, and correctness can only be verified by executing the simulator, single-pass prediction fails systematically on fine-grained dynamics, complex trajectories, and multi-stage interactions.

## Key Contributions
- A closed-loop agentic framework: program generator → physics simulator → stage-specific verifier → planner → targeted repair. Each physical specification is treated as an executable hypothesis rather than a final answer.
- A progressive validation schedule that locks in verified sub-decisions (scene reconstruction before rollout, rollout before synthesis), stored in a compact memory so later repairs preserve what already works.
- A semantic physics-control API (linear/angular velocity initialization, scheduled force/torque actuation, disturbance injection, pose assignment, object fixation) that makes motion specification compositional and expressive while shielding the agent from brittle low-level simulator commands.

## Method
Given an input image and event prompt, PhysAgent factorizes the physical representation into a scene state (grounded objects, material/physical attributes, support geometry, camera params) and an event program instantiated via the action API. A VLM-based generator proposes the program; the physics simulator executes it; a stage-specific verifier inspects intermediate artifacts; the planner converts each failure diagnosis into a symbolic edit. After passing all verification stages, the validated rollout is rendered as a structured motion prior for an image-to-video diffusion model.

## Why It Matters
PhysAgent demonstrates that physics control for video generation is fundamentally a test-and-repair problem, not a parameter-estimation problem. The execution-aware agentic loop improves physical plausibility, prompt alignment, and cross-scenario generalization. The reflective loop design generalizes naturally to other agentic systems where correctness can be verified by execution—a key pattern for robust autonomous agents.

### Score: 85/100 · [2607.16352](https://arxiv.org/abs/2607.16352) · Clarify Before Executing: A Self-Evolving Agent for Resolving Intent Asymmetry in 3D Tool Orchestration

**Authors:** Xiaoye Zhu, Weixin Li, Junan Huo, Bozhong Wang, Jia Zeng et al. | Code: https://github.com/xyzhu1225/CLARE

## TL;DR
CLARE is a self-evolving 3D agent that proactively asks clarifying questions to resolve underspecified user instructions before invoking expensive 3D tools, learning its clarification policy through simulated multi-turn RL optimization (Multi-turn Reward) rather than hand-crafted rules—more than doubling baselines on the new 3D-Clarify benchmark.

## Problem
Modern 3D toolchains (text-to-3D generation, reconstruction, point cloud editing, post-processing) require precise numerical parameters, but users naturally express goals in vague, ambiguous, or incomplete terms. Existing 3D agents assume complete intent and proceed to execution, propagating errors downstream. The key tension: how much to clarify (and what to ask) without frustrating users with unnecessary rounds.

## Key Contributions
- A four-role agent architecture: Intent Analyst (flags ambiguities) → Clarification Generator (formulates targeted questions) → Specification Composer (translates clarified intent to tool params) → Tool Executor. The pipeline decouples intent resolution from expensive tool invocation.
- Multi-turn Reward: a learned objective that jointly optimizes interaction efficiency (minimizing clarification rounds) and task-completion success, enabling the agent to self-evolve its clarification policy via simulated multi-turn dialogues.
- 3D-Clarify: a 620-scenario benchmark with three injected ambiguity types (underspecified, missing, mistaken) across five 3D domains, providing a rigorous testbed for intent asymmetry research.

## Method
The agent decomposes each user request into intent categories and identifies which parameters are ambiguous, missing, or contradictory. The Clarification Generator proposes minimal, high-value questions; responses are incorporated into a refined specification before tool invocation. Policy learning uses simulated multi-turn dialogues optimized by the Multi-turn Reward, where the agent internalizes the efficiency-accuracy tradeoff through self-play. On 3D-Clarify, CLARE achieves 60.40% (single-step) and 43.34% (multi-step) success rates vs. baselines below 30%.

## Why It Matters
Proactive clarification is a missing capability in current AI agents, which silently hallucinate reasonable-sounding parameters under ambiguity. CLARE shows that self-evolving clarification policies can be learned without manual rule engineering, and the framework is broadly applicable to any agentic pipeline where tool invocation is expensive and user intent is naturally underspecified.

### Score: 81/100 · [2607.18217](https://arxiv.org/abs/2607.18217) · HOMIE: Human-object Centric Video Personalization via Multimodal Intelligent Enhancement

**Authors:** Yiyang Cai, Nan Chen, Rongchang Xie, Junwen Pan, Chunyang Jiang et al. | Project: https://yiyangcai.github.io/homie-page.github.io/

## TL;DR
HOMIE unifies inter-subject and intra-subject human-object video personalization in a single framework by injecting MLLM knowledge into a video diffusion transformer through Global Multimodal Guidance (GMG) and Modality-Reference Embedding (MRE), achieving SOTA fidelity and interaction accuracy without costly re-alignment of the text encoder.

## Problem
Subject-driven video generation for human-object interactions (HOCVP) faces two intertwined challenges: (1) in inter-subject settings, balancing multi-subject fidelity with accurate interaction dynamics is hard, especially for abstract references like logos; (2) in intra-subject settings (multi-view or OCR map references), existing methods lack mechanisms to extract latent correspondence without expensive 3D priors. Both stem from MLLM integration strategies that either bottleneck MLLM features through the text embedding space or displace the text encoder entirely.

## Key Contributions
- Global Multimodal Guidance (GMG): injects MLLM-derived global representations into the query-key product of video token self-attention at each DiT block, adding temporal interaction modeling without architectural re-alignment.
- Modality-Reference Embedding (MRE): explicitly distinguishes token types by modality and associates multiple intra-subject references in a shared embedding space, improving identity fidelity for OCR maps and multi-view inputs.
- Unified MLLM integration strategy (Fig. 2c) that keeps the text encoder intact, letting the MLLM focus exclusively on reference relationship extraction rather than reconstructing general text-to-video control.

## Method
HOMIE builds on a video diffusion transformer (DiT). Reference images are jointly processed by an MLLM to produce global semantic tokens encoding inter-/intra-subject relationships. GMG injects these as auxiliary representations into each self-attention layer's query-key computation. MRE assigns learnable modality embeddings per token type and jointly encodes intra-subject associations. Training uses a two-stage strategy with extensive human annotation for both prompt adherence and subject consistency metrics, validated across multi-human-object personalization, abstract concept personalization, and multi-view/OCR intra-subject settings.

## Why It Matters
HOMIE advances the frontier of controllable video generation in the practically important human-video domain. Its design principle—preserve the text encoder, let the MLLM handle reference reasoning—is a cleaner architectural pattern than prior approaches that force MLLM features through constrained alignment spaces. The framework sets a new reference for MLLM-integrated video generation and personalization.
