### Score: 86/100 — [PE-Field 4D: Video Generation Models as Canvas](https://arxiv.org/abs/2607.15667)

**Authors:** Yunpeng Bai, Haoxiang Li, Qixing Huang  
*UT Austin / Pixocial — [Code](https://github.com/MTLab/PE-Field)*

## TL;DR
PE-Field 4D extends the PE-Field positional encoding paradigm from image to video diffusion transformers, enabling geometry-aware controllable video generation (camera re-trajectory, novel-view video synthesis, 4D video editing) by injecting projected positional encodings into a new cross-attention mechanism without retraining the video backbone.

## Problem
Video diffusion transformers can synthesize realistic short clips but fail to faithfully control scene geometry under viewpoint changes or camera motion. Existing camera control methods either use pose parameters as generation conditions (lacking explicit geometric structure, leading to inaccurate control) or rely on prior 4D reconstruction (limited by reconstruction quality, not generalizable). No unified, training-light mechanism exists for injecting spatial geometry into video generation while preserving the pretrained generative prior.

## Key Contributions
- **PE-Field extension to video DiTs:** Demonstrates that assigning context tokens the positional encodings of their projected target-view coordinates actively routes attention toward geometrically aligned source content — converting positional encoding from passive indexing into a geometric routing signal, now validated in video (not just image) generation models.
- **Geometry-aware cross-attention:** Augments a pretrained video DiT with a cross-attention module where generated video latent tokens attend to structured context tokens (derived from reference images/frames) encoded with target-view projected positions, injecting geometric guidance while leaving the video model's original self-attention and positional encoding intact.
- **Projected positional encoding with depth disambiguation:** Combines target-view 2D reprojection with a depth offset injected into the temporal positional coordinate, disambiguating multiple source tokens that project to similar 2D locations; resolves temporal compression ambiguity by ensuring one-to-one latent-frame-to-source-frame correspondence.

## Method
Given reference images/frames and a target camera trajectory, the framework reconstructs scene depth and projects reference content to the target view, building position-aligned context tokens. These receive projected positional encodings (target-view 2D + depth-aware temporal offset). A geometry-aware cross-attention module — injected into the pretrained video DiT — lets each generated latent token attend globally to the video's own context and locally to the geometry-tagged reference tokens. The original spatiotemporal positional encoding of the generated video latents is left unchanged, preserving the pretrained generative prior while allowing geometric guidance to be injected through the new cross-attention pathway.

## Why It Matters
Camera-controlled video generation and novel-view video synthesis are foundational for professional video production, AR/VR content, and world model development. PE-Field 4D provides a principled, training-light approach that reuses pretrained large-scale video generative priors (WAN2.1/2.2-scale) to enable precise geometric control via a clever positional encoding reformulation — no dense NeRF or expensive explicit reconstruction required at inference. The framework also unifies spatial memory and camera control under a single mechanism, suggesting broad future applicability.

### Score: 85/100 — [SlotMem: Character-Addressable Internal Memory for Narrative Long Video Generation](https://arxiv.org/abs/2607.15772)

**Authors:** Yilai Liu, Xin Zhang, Shiyuan Zhang, Hongyang Du  
*University of Hong Kong / Tsinghua University — [Code](https://github.com/YilaiLiu-HKU/SlotMem)*

## TL;DR
SlotMem introduces character-addressable slot memory into autoregressive video diffusion: each recurring character is represented as a compact, continuously updated memory state extracted from DiT feature tokens, which is injected exclusively into that character's spatially localized tokens during generation — eliminating identity drift in multi-character narrative long video generation.

## Problem
Autoregressive long video generation (chunk-by-chunk) suffers from identity drift: when a character disappears and reappears after a temporal gap, the model reconstructs them inconsistently because the limited rolling context window loses character-specific appearance details. Prior memory approaches retrieve whole keyframes (entangling character identity with background, pose, lighting) or reuse coarse frame-level KV caches — neither providing fine-grained, character-specific, continuously updated memory decoupled from other visual factors.

## Key Contributions
- **Character-Semantic Probe:** Localizes which spatial tokens in the DiT feature map belong to a given character by analyzing cross-attention weights between character text tokens and image features, producing character-specific spatial masks without extra supervision.
- **Role-wise slot memory with Memory Encoder:** Compresses character-localized DiT tokens into compact per-character slot vectors, storing identity information disentangled from background and co-occurring characters; under a fixed memory budget, new observations are consolidated into existing slots rather than appended as additional frames.
- **Memory Writer + Character-Wise Cross-Attention:** A Memory Writer conservatively updates each character's slots (only when confidence is high, avoiding overwriting with noisy/occluded frames); Character-Wise Cross-Attention retrieves slot memory and injects it only into spatially localized tokens of the matching character during generation, preventing cross-character contamination.

## Method
Built on WAN 2.2. When generating a new chunk, the Character-Semantic Probe analyzes cross-attention activations between each character's text token and DiT features to produce a spatial mask. The Memory Encoder compresses masked tokens into per-character slot vectors. The Memory Writer updates stored slots from new observations conservatively (gating on visibility confidence), evolving character memory rather than discarding and re-appending keyframes. During subsequent chunk generation, Character-Wise Cross-Attention queries each character's slot memory and injects retrieved features only at the spatial locations identified by that character's probe mask — preventing identity bleeding between characters. Training uses narrative video data with annotations aligning character text mentions to video segments.

## Why It Matters
Multi-scene narrative long video generation — for animated stories, VR experiences, or long-form content creation — requires maintaining distinct, stable identities across arbitrary time gaps between character appearances. SlotMem directly addresses this failure mode through principled disentanglement of character identity from incidental visual context, and is compatible with leading open video diffusion models. The character-slot abstraction is also a natural substrate for future story-driven controllable generation.

### Score: 82/100 — [Test-Time Noise Guided Adaptation for Realistic Autoregressive Video Generation](https://arxiv.org/abs/2607.15849)

**Authors:** Dimitrios Karageorgiou, Symeon Papadopoulos, Ioannis Kompatsiaris, Efstratios Gavves  
*CERTH / University of Amsterdam — [Project](https://mever-team.github.io/tango)*

## TL;DR
TANGO (Terminal points Avoidance through Noise Guided Optimization) is a training-free test-time method that uses the diffusion model as a critic of its own autoregressive outputs — checking whether predicted noise matches the expected isotropic Gaussian — to detect and escape "terminal points" where the generated trajectory would otherwise collapse into unrealistic territory.

## Problem
Autoregressive video diffusion models generate arbitrarily long videos chunk-by-chunk but suffer from a previously undercharacterized failure mode: even when each individual generated frame lies on the real data manifold, the joint trajectory can reach a "terminal point" — a state from which no valid continuation exists in the training distribution — forcing the model to produce increasingly unrealistic video. Existing fixes (exposure bias training, attention sinks, denoising re-runs) address frame-level realism but miss this trajectory-level failure.

## Key Contributions
- **Terminal point formalization:** Defines and characterizes terminal points as generated states where the individual frames are realistic but the joint trajectory has no valid continuation in the training distribution — a distinct failure mode from frame-level manifold deviation, not addressed by prior art.
- **Noise consistency hypothesis:** Proposes that for well-modeled conditioning sequences, the noise predicted by the diffusion model one step forward should be approximately isotropic Gaussian; deviations from Gaussianity are a reliable signal that the current trajectory is at or near a terminal point.
- **Test-time constrained optimization:** TANGO performs a forward step from the current generated sequence, measures how far predicted noise deviates from isotropic Gaussian, and searches (via constrained optimization in the neighborhood of the current output) for an alternative trajectory avoiding the terminal — no model retraining required.

## Method
At each autoregressive step, before committing to the next generated frames, TANGO re-feeds the current generated sequence into the denoising model and predicts noise. If the KL divergence of predicted noise from the isotropic Gaussian exceeds a threshold, TANGO runs a constrained optimization that perturbs the current trajectory (within a neighborhood of the original output to preserve visual coherence) to minimize this divergence, steering the generative process back toward the in-distribution manifold. The optimization is lightweight (gradient-based, few steps) and the method is plug-in compatible with any autoregressive diffusion model. Applicability is confirmed for flow-matching models as well.

## Why It Matters
Long video generation (>15 seconds) is precisely where autoregressive models most visibly fail. TANGO provides a principled, training-free remedy for a failure mode that prior work did not recognize as distinct from frame-level artifacts, achieving a 3.1% absolute improvement on VBench and 28.3% FVD reduction across 15-second videos — substantial gains applicable on top of state-of-the-art models like Wan2.2 without any retraining or architecture changes.

### Score: 81/100 — [Searching Videos as Trees: Self-Correcting Agents for Grounded Long Video QA](https://arxiv.org/abs/2607.16189)

**Authors:** Ce Zhang, Ziyang Wang, Yulu Pan, Oluwatumininu Oguntola, Pranav Wagh, Qiyu Wu, Hiromi Wakaki, Mohit Bansal, Gedas Bertasius  
*UNC Chapel Hill / Sony — [Code](https://github.com/CeeZh/VTS)*

## TL;DR
VideoTreeSearch (VTS) casts grounded long-video question answering as agentic navigation over an adaptive temporal tree, training a VLM with four discrete operations (zoom_in, zoom_out, shift, answer) that make backtracking and self-correction explicitly learnable — achieving +12.5 mIoU on CG-Bench and improving general long-video QA by up to +7.1 points.

## Problem
Grounded long-video QA requires both localizing a brief evidence interval and answering the question. Current agentic methods use a single continuous `crop_video(start, end)` action for iterative search, which supports coarse-to-fine narrowing but provides no mechanism for fine-to-coarse backtracking when the agent commits to the wrong region. Without explicit self-correction primitives, agents converge prematurely after wrong early decisions and cannot recover.

## Key Contributions
- **Adaptive temporal tree construction:** Builds a non-uniform tree from visual scene boundaries detected via CLIP embeddings, so each node is a semantically coherent segment — structuring the search space so localization reduces to selecting a node rather than regressing precise timestamps from raw pixels.
- **Discrete action space with explicit backtracking:** Four operations (zoom_in → descend to child, zoom_out → ascend to parent, shift → move to sibling, answer → commit) make coarse-to-fine narrowing and fine-to-coarse recovery independently learnable behaviors with dedicated training signal.
- **Trajectory synthesis with deliberate detours:** Synthesizes training trajectories that include intentional wrong-branch navigation followed by explicit recovery via zoom_out and shift — providing supervised signal for self-correction, not just successful search; followed by RL with grounding and answer-accuracy rewards.

## Method
VTS constructs the temporal tree at inference time by detecting visual scene boundaries using CLIP feature similarity across uniformly sampled frames and splitting nodes recursively at high-dissimilarity boundaries. The agent (a fine-tuned VLM) receives a summary of the current node's video segment plus question and navigation history, and outputs one of the four discrete actions. Training proceeds in two phases: (1) SFT on synthesized trajectories that include both correct paths and deliberate-detour-then-recovery paths; (2) RL with outcome-based grounding and answer accuracy rewards. The tree structure is content-adaptive (deeper where scene boundaries are dense), so the agent's navigation depth naturally scales with video complexity.

## Why It Matters
Efficient evidence localization within long videos is fundamental to practical video retrieval, video QA assistants, and video-grounded reasoning agents. VTS demonstrates that a structured hierarchical representation combined with explicit backtracking primitives — both supervised via synthetic trajectories — dramatically outperforms continuous search on grounded LVQA benchmarks (+12.5 mIoU on CG-Bench), and these benefits transfer to general long-video understanding tasks. The discrete action space also makes the agent's reasoning transparent and auditable.
