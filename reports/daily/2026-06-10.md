### 1. ARM: An AutoRegressive Large Multimodal Model with Unified Discrete Representations

**Score: 87/100** · [arXiv:2606.11188](https://arxiv.org/abs/2606.11188) · [Project](https://github.com/wdrink/ARM)

**Authors:** Junke Wang, Xiao Wang, Jiacheng Pan, Xuefeng Hu, Feng Li, Jingxiang Sun

## TL;DR
ARM is a unified 7B autoregressive model that handles image understanding, generation, and editing through a single next-token prediction framework, achieving state-of-the-art across all three tasks via a novel discrete tokenizer with complementary supervision objectives and GRPO-based preference alignment — with RL-induced cross-task synergy between generation and editing.

## Problem
Existing unified multimodal models either decouple understanding and generation into separate encoders (structurally fragmented, costly at inference), or use a shared generation-oriented tokenizer that sacrifices understanding quality for synthesis fidelity. No prior work achieves genuine unification without trade-offs across understanding, generation, and editing.

## Key Contributions
- **Unified discrete visual tokenizer** jointly supervised with four complementary objectives (caption loss, pixel reconstruction via a lightweight diffusion decoder, SigLIP2 sigmoid contrastive loss, and feature distillation), ensuring the same discrete tokens support recognition, synthesis, and editing in a single shared latent space.
- **7B autoregressive multimodal model** trained over interleaved text + image token sequences, achieving 40.2 on MMMU, 87.3 on POPE, 0.86 on GenEval, 0.56 on WISE, and leading scores on GEdit-Bench-EN (G_O 6.68).
- **GRPO preference alignment** applied only to visual token prediction, using GPT-o3 and GPT-4.1 as reward models; RL not only improves target tasks but induces cross-task synergy — optimizing generation improves editing and vice versa, without degrading understanding.

## Method
ARM uses a frozen SigLIP2-SO400M-512 encoder with FSQ quantization (65K codebook) and projection modules trained with four losses. A 7B Qwen2.5-based LLM backbone models all modalities via next-token prediction. Detokenization uses a FLUX.1-initialized latent diffusion decoder conditioned on quantized embeddings. Training proceeds in 4 stages: pretraining (2.5T multimodal tokens), continued training (higher resolution + interleaved data), SFT, then RL via VeRL. Dynamic resolution support is implemented via shape tokens in the text prompt.

## Why It Matters
ARM demonstrates that a single discrete visual representation — when trained with carefully balanced supervision objectives — can serve both understanding and generation without compromise. The cross-task RL synergy finding is particularly valuable: it suggests that preference optimization of visual token prediction is a broadly applicable improvement that benefits the whole task family. The open-sourced code provides a clean and scalable blueprint for unified AR multimodal models.

### 2. Data Journalist Agent: Transforming Data into Verifiable Multimodal Stories

**Score: 82/100** · [arXiv:2606.11176](https://arxiv.org/abs/2606.11176) · [Project](https://data2story.github.io)

**Authors:** Kevin Qinghong Lin, Batu EI, Yuhong Shi, Pan Lu, Philip Torr, James Zou

## TL;DR
Data2Story is a 7-agent virtual newsroom that transforms raw datasets into verifiable, interactive multimedia news articles, where every claim is traceable back to executable code or a source URL via a dedicated Inspector agent — making the full reasoning chain auditable end-to-end.

## Problem
High-quality data journalism requires coordinating weeks of work across multiple specialists (context research, statistical analysis, angle selection, visual design, web publishing). Current agents handle individual steps (data analysis, visualization) but cannot serve as end-to-end journalists. Critically, no existing system provides verifiable, claim-level evidence traceability — readers and editors cannot confirm where a number came from or whether a chart accurately reflects the underlying data.

## Key Contributions
- **Multi-agent virtual newsroom**: 7 specialized roles (Detective, Analyst, Editor, Designer, Programmer, Auditor, Inspector) orchestrated into a coherent pipeline from raw data to interactive HTML article.
- **Inspector agent**: links every published claim (numbers, charts, interactive elements) back to the exact code line or source URL that generated it, enabling full auditability — grounding at the individual-claim level far exceeds what human-authored articles provide.
- **Multimodal article generation**: Designer reasons about what readers will want to see given the topic, deploying appropriate tools (interactive maps for geography, audio clips for music, animated charts for data patterns) rather than defaulting to plain text.

## Method
Data2Story routes a raw dataset through 7 roles in sequence: Detective (web search for external context), Analyst (enumerate all analyses, run Python code, record provenance per-finding), Editor (choose angles, rank by priority, draft paragraph-level plan), Designer (select per-section multimedia assets via tool calls), Programmer (render interactive HTML), Auditor (flag visual/structural defects for revision), Inspector (bind each HTML fragment to its supporting evidence — code line or URL). Evaluation was on 18 articles across diverse topics, with 53 human participants rating on 5 rubric dimensions, computer-use agents as low-cost automatic judges, and a verifiability checker that re-executes claims against data.

## Why It Matters
Verifiable, evidence-grounded agentic output is one of the central challenges for multi-agent systems deployed in high-stakes domains. Data2Story demonstrates a practical solution: claim-level provenance tracking by a dedicated Inspector agent. The finding that human articles retain an edge in editorial angle and creative design while Data2Story dominates in auditability and transparency clarifies the right role for agentic journalism systems — as collaborators that handle computation and verification, not as replacements for editorial judgment.

### 3. Next Forcing: Causal World Modeling with Multi-Chunk Prediction

**Score: 81/100** · [arXiv:2606.11187](https://arxiv.org/abs/2606.11187) · [Project](https://gangweix.github.io/next-forcing/)

**Authors:** Gangwei Xu, Qihang Zhang, Jiaming Zhou, Xing Zhu, Yujun Shen, Xin Yang

## TL;DR
Next Forcing introduces multi-chunk prediction (MCP) to cure "myopic supervision" in autoregressive video world models, achieving 2.3× faster training convergence at 50 fps, 2× inference speedup, and new SOTA on RoboTwin (94.1/93.5% Clean/Random) by training auxiliary modules to simultaneously denoise video chunks at multiple future temporal horizons.

## Problem
Autoregressive video world models trained with teacher forcing suffer from "myopic supervision": the single-chunk prediction target allows an appearance shortcut where the model learns near-identity maps between visually similar adjacent frames rather than the true underlying dynamics. This pathology worsens at high frame rates (50 fps) where adjacent frames are nearly identical, causing significantly slower convergence and lower accuracy.

## Key Contributions
- **Multi-chunk prediction (MCP) objective**: lightweight auxiliary modules predict video at next¹, next², next³ temporal horizons simultaneously, providing dense multi-scale temporal supervision that forces the main model to learn trajectory-level dynamics rather than appearance shortcuts.
- **Chained MCP modules with multi-layer feature fusion**: each MCP depth fuses intermediate features from 4 layers of the main model (layers 4, 12, 20, 30) and builds on the prior depth, so gradients propagate back into early representations and near-future predictions inform farther-future ones.
- **2× inference acceleration**: at inference, MCP modules predict the next chunk in parallel with the current one, enabling parallel chunk generation with no additional training cost.

## Method
Next Forcing augments the standard teacher-forcing flow matching objective with MCP. For each of 3 MCP depths k ∈ {1,2,3}, a shifted target is constructed by advancing the video latent by k chunks. Each target is independently noised at a higher timestep shift (s_mcp > s_main) to force reliance on the main model's representations. Three lightweight transformer blocks (3 layers each) process the fused multi-layer features and noisy shifted target to predict the flow matching velocity for each future chunk. The causal chain (depth k+1 builds on depth k output) propagates information across prediction horizons. The Mixture-of-Transformers architecture jointly models video and action streams; improved video representations benefit action decoding through shared cross-modal attention.

## Why It Matters
MCP for video generation is the direct analog of multi-token prediction in LLMs — a training objective change that yields large gains in both efficiency and quality without architecture redesign. The 50% FVD reduction on general video pretraining (3.5M clips) confirms the benefit generalizes beyond robot data. The 2.3× convergence speedup at 50 fps translates directly to lower training costs for WAMs, which currently dominate embodied AI research. This is a drop-in improvement for any autoregressive video world model.

### 4. A History-Aware Visually Grounded Critic for Computer Use Agents

**Score: 81/100** · [arXiv:2606.11078](https://arxiv.org/abs/2606.11078) · [Code](https://github.com/G-JWLee/HiViG)

**Authors:** Jaewoo Lee, Zaid Khan, Archiki Prasad, Justin Chih-Yao Chen, Supriyo Chakraborty, Kartik Balasubramaniam

## TL;DR
HiViG is a test-time critic for Computer Use Agents that combines macro-action history tracking (to prevent short-sighted planning) with visually grounded action verification (to catch spatial errors before execution), achieving 15% absolute improvement on WebArenaLitev2 and outperforming all existing critics across web, mobile, and desktop benchmarks.

## Problem
Computer Use Agents (CUAs) navigating GUI environments make mistakes that compound over long horizons. Existing critics either provide only scalar rewards (uninformative when all candidates are poor) or verbal feedback with two critical blindspots: (1) they forget earlier actions and fall into short-sighted decision loops, and (2) they verify actions by the policy's verbalized intent rather than the actual pixel coordinates on screen, missing spatial grounding errors.

## Key Contributions
- **Macro-action history**: the HiViG critic recursively compresses past interactions into compact multi-step achieved goals (e.g., "Successfully opened the Downloads directory"), providing the policy with long-horizon task progress tracking at each decision step to prevent redundant or regressive actions.
- **Visually grounded error analysis**: critic renders a visual marker (red X) at the proposed action's exact pixel coordinates on the screenshot and reasons about whether the correct UI element is targeted, identifying 12 error dimensions before execution rather than after.
- Trained on 52K SFT samples derived from ScaleCUA GUI trajectories; improves Gemini-3-Flash by 15% absolute on WebArenaLitev2 (30.5%→45.5%) and outperforms strongest baseline critics by 9.0% (Gemini) and 5.8% (Qwen3-VL-32B) on average across platforms.

## Method
HiViG trains a multimodal critic on two datasets: (1) History state tracking — iterative compression using an MLLM annotator that processes consecutive GUI state transitions into macro-action history updates; (2) Visually grounded error analysis — synthesizes 12 error dimension variants of expert actions, with multi-stage rationales generated by conditioning on visual markers at action coordinates. At test time, HiViG operates in two phases at each step: first updating the macro-action history from the last visual state change, then evaluating the proposed action using the visual marker and predicted state-transition. If rated "Bad," the critic classifies the error and provides verbal corrective guidance before execution.

## Why It Matters
GUI automation is a major practical frontier for agentic AI. HiViG reveals that existing critics — even strong verbal ones — overlook two critical capabilities: history tracking and visual grounding. The finding that existing critics can hurt already-capable policies (CGI-8B degrades Gemini by 3.9 points on WebArenaLitev2) is a warning for practitioners. The cross-platform generalization to web, mobile, and desktop with a single critic demonstrates that the failure modes being addressed are fundamental to GUI interaction rather than domain-specific.

### 5. BiWM: Advancing Open-Source Interactive Video World Models with Bidirectional Autoregression

**Score: 80/100** · [arXiv:2606.10135](https://arxiv.org/abs/2606.10135) · [Code](https://github.com/LynnReal-AI/BiWM)

**Authors:** Shaohao Rui, Xiaofeng Mao, Zhanyu Zhang, Peijia Lin, Yansong Zhu, Yibo Zhang

## TL;DR
BiWM is the first open-source full-stack framework for bidirectional autoregressive video world models — where all frames within each generated chunk retain full bidirectional attention and are re-encoded each step — achieving better fidelity and camera controllability than causal models using only 2 training stages (vs. 4 in minWM), with support for Wan2.1/2.2, HunyuanVideo, and LTX backbones.

## Problem
Causal autoregressive world models freeze generated frames into a KV cache, making errors permanent and compounding — causing visual degradation and camera drift over long rollouts, especially under camera control. Bidirectional models (Yume-1.5, Matrix-Game-3.0) avoid this via continuous self-correction but no open-source framework implements the paradigm, making their strong results hard to reproduce or extend.

## Key Contributions
- **First open-source bidirectional autoregressive world model framework**: each chunk retains full bidirectional attention over the whole current chunk + history (history is re-encoded every step, not frozen), self-correcting camera drift and visual errors that accumulate under causal models.
- **Two-stage training recipe**: camera-text pretraining (inject discrete camera-action tokens through the text path, ~100 steps) + multi-objective DMD distillation, vs. four stages in minWM — both stages converge within hundreds of steps on 8×H200 GPUs.
- **Anti-degradation DMD objectives**: adversarial (GAN) + forward-KL mass-covering anchor that prevents the mode-seeking collapse inherent in standard distribution-matching distillation, preserving scene dynamics and motion diversity.

## Method
BiWM starts from a pretrained bidirectional video diffusion backbone (Wan2.1-1.3B, Wan2.2-5B, HunyuanVideo-1.5-8B, or LTX-2.3-22B). Stage 1 injects camera control by appending discrete camera-action tokens to the text conditioning path — no new parameters, converging ~100 steps. Stage 2 performs DMD with self-rollout (following Self-Forcing) in the chunk-wise bidirectional setting, augmented with GAN and forward-KL objectives to counter mode collapse. For long-horizon rollout, BiWM provides pluggable history compression (FramePack-style pyramid layout, PackForcing-style encoder, or sink-based sliding window). An optional NVFP4 4-bit pipeline enables deployment-time inference acceleration.

## Why It Matters
Open-sourcing the bidirectional world model paradigm enables academia to reproduce and extend claims from closed systems (Yume, Matrix-Game) that currently report empirical advantages over causal approaches. The key architectural insight — that error accumulation under causal AR is suppressed by bidirectional re-encoding — is simple and important. The extreme training efficiency (hundreds of steps on 8 H200s, two stages vs. four) makes this accessible to resource-constrained labs, potentially accelerating research at the intersection of video generation and embodied AI.
